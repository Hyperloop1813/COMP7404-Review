# Question 1

### 1. Greedy GSA search is guaranteed to terminate in finite graphs.
* **判断**：**True (正确)**
* **解析**：GSA代表图搜索算法（Graph Search Algorithm）。图搜索会维护一个“已探索集合”（Explored Set / Closed List）来记录已经访问过的节点。在有限图中，由于节点数量有限且图搜索不会重复扩展已探索的节点（避免了无限循环），因此贪心图搜索（Greedy GSA）一定会在有限步内终止（要么找到目标，要么遍历完所有可达节点）。

### 2. BFS TSA always explores nodes in increasing order of their path cost.
* **判断**：**False (错误)**
* **解析**：TSA代表树搜索算法（Tree Search Algorithm）。广度优先搜索（BFS）是按照节点的**深度（Depth）**递增的顺序来扩展节点的，而不是**路径代价（Path Cost）**。只有当图中所有边的代价（Step Cost）都相同时，深度才等同于路径代价。如果边的代价不同，BFS可能会先扩展深度浅但代价高的节点。按路径代价递增顺序扩展的是一致代价搜索（Uniform Cost Search, UCS）。

### 3. Recursive DFS can fail due to stack overflow in large graphs.
* **判断**：**True (正确)**
* **解析**：递归实现的深度优先搜索（DFS）将每一层递归调用压入系统的调用栈中。在非常大或极深的图中，递归的深度可能会超过系统分配给栈内存的限制，从而导致栈溢出（Stack Overflow）错误。

### 4. If the heuristic h(n) is admissible but not consistent, A* TSA may revisit nodes.
* **判断**：**True (正确)**
* **解析**：首先，树搜索算法（TSA）本身不维护“已探索集合”（Closed List），所以不管启发式函数如何，只要存在多条路径到达同一个状态，TSA都会重复访问节点。其次，即使是在图搜索（GSA）中，如果启发式函数是容许的（Admissible）但不一致（Not Consistent），算法在首次扩展某节点时可能找到的不是最优路径，为了保证A*的最优性，算法**必须**允许重新打开（revisit/reopen）已经访问过的节点。因此这句话是正确的。

### 5. A* will always expand fewer nodes than BFS if an admissible heuristic is used.
* **判断**：**False (错误)**
* **解析**：题目中使用了“always”（总是）。虽然A*通常比BFS更高效，但如果在极端情况下（例如启发式函数 $h(n) = 0$，这也是一个容许的启发式函数），A*算法就退化成了单纯的代价搜索（UCS）。在这种情况下，A*扩展的节点数量可能和BFS完全一样，而不是“总是更少”。

### 6. DFS TSA can be implemented using either recursion or an explicit stack.
* **判断**：**True (正确)**
* **解析**：深度优先搜索（DFS）的后进先出（LIFO）特性可以通过两种标准方式实现：一是利用编程语言本身的函数调用栈（即递归），二是使用显式的数据结构栈（Stack）配合循环来实现（即迭代法）。

### 7. DFS GSA is guaranteed to visit all nodes in a finite connected graph.
* **判断**：**True (正确)**
* **解析**：在有限连通图中，从任何一个节点出发都存在到达其他所有节点的路径。由于这是图搜索算法（GSA），它使用已探索集合避免了在环中无限循环。如果没有设定提前终止的目标（或者目标不存在），DFS GSA最终一定会遍历并访问图中所有的连通节点。

### 8. Alpha-Beta pruning reduces the effective branching factor of the game tree without affecting the result.
* **判断**：**True (正确)**
* **解析**：这是Alpha-Beta剪枝的核心特性。它通过剪去那些注定不会被理性的对手或自己选择的分支，减少了需要评估的节点数（即降低了有效分支因子），但它返回的极小极大值（Minimax value）和不剪枝的原始Minimax算法完全一样。

### 9. The order in which moves are evaluated does not affect the efficiency of Alpha-Beta pruning.
* **判断**：**False (错误)**
* **解析**：Alpha-Beta剪枝的效率**高度依赖**于节点的评估顺序。如果能优先评估最优的走步（好的排序），可以极大程度地触发剪枝，从而探索极少的节点；如果是最差的排序，将不会发生任何剪枝，退化为基础的Minimax算法。

### 10. In the worst case, Alpha-Beta pruning explores the same number of nodes as Minimax.
* **判断**：**True (正确)**
* **解析**：如第9题所述，如果走步的生成顺序是最差的（例如，每次都先探索最不利的分支），Alpha-Beta剪枝就无法进行任何剪枝操作。在这种最坏情况下，它不得不展开整棵博弈树，探索的节点数量与普通的Minimax算法完全相同。

### 11. In games with large state spaces, an evaluation function estimates the utility of non-terminal states.
* **判断**：**True (正确)**
* **解析**：在像国际象棋或围棋这样状态空间极其庞大的游戏中，搜索到底层（终局状态）是不可能的。因此，算法会在达到一定的深度限制时停止搜索，并使用一个启发式的“评估函数”（Evaluation Function）来估算当前非叶子节点（非终局状态）的预期效用（胜率或得分）。

### 12. The "horizon effect" occurs when the search algorithm fails to look deep enough to foresee critical moves.
* **判断**：**True (正确)**
* **解析**：“地平线效应”（Horizon Effect）是博弈树搜索中的经典问题。当算法由于深度限制（搜索地平线）而无法看到足够远的未来时，它可能会做出短视的决定（例如通过牺牲小棋子来推迟不可避免的“将死”，将灾难推到搜索地平线之外，但实际上并没有解决问题）。

### 13. A policy π(s) in an MDP maps states to actions.
* **判断**：**True (正确)**
* **解析**：在马尔可夫决策过程（MDP）中，策略（Policy）$\pi$ 的定义就是一个从状态空间到动作空间的映射。它告诉智能体在特定的状态 $s$ 下应该采取什么动作 $a$。

### 14. The optimal policy for an MDP is always unique.
* **判断**：**False (错误)**
* **解析**：最优策略不一定是唯一的。在同一个MDP中，可能会有多个不同的动作在某个状态下产生完全相同的最高期望累积回报（即最优Q值相同）。在这种情况下，选择其中任何一个动作都能形成最优策略，因此可以存在多个最优策略，但它们对应的“最优价值函数”（Optimal Value Function）一定是唯一的。

### 15. The epsilon-greedy strategy ensures that the agent always selects the action with the highest Q-value.
* **判断**：**False (错误)**
* **解析**：$\epsilon$-greedy（$\epsilon$-贪心）策略在 $1-\epsilon$ 的概率下选择当前Q值最高的动作（利用，Exploitation），但在 $\epsilon$ 的概率下会**随机选择**一个动作（探索，Exploration），而不管它的Q值是多少。因此它并不是“总是”（always）选择最高Q值的动作。

### 16. Q-learning is a model-free reinforcement learning algorithm.
* **判断**：**True (正确)**
* **解析**：Q-Learning是典型的“无模型”（Model-Free）强化学习算法。它不需要知道环境的转移概率模型 $P(s'|s,a)$ 或奖励函数 $R(s,a)$，只需通过智能体与环境交互得到的样本 $(s, a, r, s')$ 来直接更新Q值表。

### 17. In approximate Q-learning, the agent updates the Q-value for a state-action pair using the Bellman equation.
* **判断**：**True (正确)**
* **解析**：在近似Q-Learning（Approximate Q-Learning / Deep Q-Learning）中，我们使用特征权重或神经网络来拟合Q值。在更新这些权重时，仍然是基于贝尔曼方程（Bellman Equation）计算出的目标值（Target: $r + \gamma \max Q(s', a')$）与当前预测值之间的误差（TD Error）来进行梯度下降更新。所以底层核心逻辑仍然是使用贝尔曼方程。

### 18. The discount factor (γ) in Q-Learning can be greater than 1 to prioritize future rewards over immediate rewards.
* **判断**：**False (错误)**
* **解析**：折扣因子 $\gamma$ 的取值范围必须在 $[0, 1]$ 之间。如果 $\gamma > 1$，未来的奖励会被无限放大，导致累积奖励的求和无法收敛（趋于无穷大），数学模型将崩溃。要想重视未来奖励，可以将 $\gamma$ 设置为接近1的值（如0.99），但绝不能大于1。

### 19. Q-Learning is guaranteed to converge to the optimal Q-values if the learning rate (α) decreases over time but never reaches zero, and all state-action pairs are explored infinitely often.
* **判断**：**True (正确)**
* **解析**：这是Q-Learning收敛到最优Q值的理论条件（Robbins-Monro条件）。需要满足两个主要条件：一是所有的状态-动作对 $(s,a)$ 都必须被无限次地访问（充分探索）；二是学习率 $\alpha$ 必须逐渐衰减，满足 $\sum \alpha = \infty$ 且 $\sum \alpha^2 < \infty$（递减但不是立刻变为0）。符合这些条件，算法保证收敛。

### 20. In Q-Learning, if the agent exclusively exploits its current Q-values without exploring, it is guaranteed to find the optimal policy.
* **判断**：**False (错误)**
* **解析**：如果智能体只进行“利用”（Exploitation）即每次只选当前Q值最高的动作，而不进行“探索”（Exploration），它极有可能陷入局部最优解。因为某些未被尝试过的状态-动作可能含有更高的实际回报，但由于初始Q值较低而被永远忽略了。这也是为什么强化学习需要 $\epsilon$-greedy 等策略来平衡探索与利用。

### Question 2.1 [8 pts]
**英文原题目:**
Below is an incomplete implementation of the A* search algorithm. Fill in the missing line(s) of code marked as `# YOUR CODE HERE` to complete the implementation.
(代码截图见原图)

**中文解答与代码注释:**
题目要求补全 A* 算法的代码。在A*搜索中，优先队列 `frontier` 中存储的节点格式为 `(f_cost, path)`。
当从 `frontier` 中取出一个节点进行扩展时，我们需要遍历其所有的邻居节点，计算新的路径代价（$g$）和启发式估值（$h$），然后将新节点加入到 `frontier` 中。

已知节点结构为 `node = (f_cost, path)`，其中 `node[0]` 是当前路径的评估代价 $f = g + h$，`node[1]` 是表示到达当前状态的路径字符串（例如 `'Sa'`）。`node[1][-1]` 就是当前所在的节点字符。

因此，补全的代码需要：
1. 遍历当前节点在 `stateSpaceGraph` 中的所有后继节点及其转移代价 `cost`。
2. 计算到达当前节点的实际路径代价 $g$。因为已知 $f = g + h$，所以 $g = \text{node}[0] - h[\text{node}[1][-1]]$。
3. 计算到达邻居节点的新 $f$ 值：$new\_f = g + \text{cost} + h[\text{neighbor}]$。
4. 将新节点 `(new_f, node[1] + neighbor)` 压入优先队列 `frontier` 中。

**完整带注释的代码如下：**
```python
from heapq import heappush, heappop

def aStarTsa(stateSpaceGraph, h, startState, goalState):
    frontier = []
    # 初始节点压入堆，格式为 (f_cost, path)，初始的 path 只有 startState
    heappush(frontier, (h[startState], startState))
    print('Initial frontier:', list(frontier))
    
    while frontier:
        node = heappop(frontier)
        # 如果路径的最后一个节点是目标状态，直接返回当前 node
        if (node[1].endswith(goalState)): return node
        # node[1][-1] 为当前所在的最新状态节点，node[0] 为当前状态的 f_cost
        print('Exploring:', node[1][-1], 'at cost', node[0])
        
        # --- YOUR CODE HERE ---
        # 遍历当前节点的所有邻居，邻居在字典中值的格式为 (cost, neighbor)
        for cost, neighbor in stateSpaceGraph[node[1][-1]]:
            # 计算到达当前节点的实际路径代价 g_cost
            # g_cost = 当前节点的 f_cost - 当前节点的 h_cost
            g_cost = node[0] - h[node[1][-1]]
            # 新节点的 f_cost = g_cost + 到达邻居的 step_cost + 邻居的 h_cost
            new_f_cost = g_cost + cost + h[neighbor]
            # 新路径 = 当前路径拼接上邻居节点的字符
            new_path = node[1] + neighbor
            # 将新节点压入优先队列
            heappush(frontier, (new_f_cost, new_path))
        # ----------------------
        
        print(list(frontier))
```

### **Question 3.1 [4 pts]: Which of the following problems can be formulated as Constraint Satisfaction Problems (CSPs)?**
*Answer the following multiple-choice questions by selecting the correct option(s). Some questions may have more than one correct answer.*

- [x] Sudoku puzzles
- [x] Map coloring problems
- [ ] Shortest path finding in graphs
- [x] Scheduling tasks without conflicts
- [ ] Sorting a list of numbers

**【中文解答与解析】**
**正确选项：Sudoku puzzles, Map coloring problems, Scheduling tasks without conflicts**

* **Sudoku puzzles (数独谜题) - 正确**：数独是经典的CSP。变量是网格中的每个空格，值域是数字1到9，约束条件是同一行、同一列和同一个3x3宫格内的数字不能重复。
* **Map coloring problems (地图着色问题) - 正确**：经典的CSP。变量是地图上的各个区域，值域是可用的颜色，约束条件是相邻的区域不能被涂成相同的颜色。
* **Shortest path finding in graphs (图中的最短路径查找) - 错误**：最短路径问题通常属于路径搜索或动态规划范畴（如A*算法、Dijkstra算法）。CSP关注的是寻找满足所有约束的状态分配，而不是寻找代价最小的动作序列或路径。
* **Scheduling tasks without conflicts (无冲突的任务调度) - 正确**：调度问题可以完美转化为CSP。变量是各个任务，值域是可用的人员、机器或时间段，约束条件是任务不能在时间或资源上发生冲突（例如一个人不能同时做两件事）。
* **Sorting a list of numbers (对数字列表排序) - 错误**：排序是一个基于比较和交换的算法问题。它不适合用定义变量、值域和预设约束的网络来求解。

### **Question 3.2 [4 pts]: Which statement(s) are True?**

- [x] A CSP consists of a set of variables, each with an associated domain of values, and a set of constraints.
- [x] Backtracking search is an algorithm commonly used to solve CSPs.
- [ ] CSPs can only have binary constraints involving two variables.
- [x] Constraint propagation techniques can reduce the search space of a CSP.
- [ ] In CSPs, variables must represent numerical quantities.

**【中文解答与解析】**
**正确选项：第1、2、4项**

* **A CSP consists of a set of variables, each with an associated domain of values, and a set of constraints. - 正确**：这是约束满足问题（CSP）的标准形式化定义：包含变量集合 $X$、值域集合 $D$ 和约束集合 $C$。
* **Backtracking search is an algorithm commonly used to solve CSPs. - 正确**：回溯搜索（深度优先搜索的一种形式，在遇到违反约束时立即回退）是求解CSP最基础且最常用的算法。
* **CSPs can only have binary constraints involving two variables. - 错误**：CSP可以包含一元约束（涉及单个变量）、二元约束（涉及两个变量）甚至高阶/全局约束（涉及三个或更多变量，如 `AllDiff` 约束）。
* **Constraint propagation techniques can reduce the search space of a CSP. - 正确**：约束传播（如前向检查、弧一致性AC-3）通过推导并剔除值域中不可能满足约束的取值，能有效缩小搜索树的规模，从而减少搜索空间。
* **In CSPs, variables must represent numerical quantities. - 错误**：CSP的变量可以是任何离散或连续的对象，不仅限于数字。例如，在地图着色中变量表示“区域”，值域表示“颜色（红、绿、蓝）”。

### **Question 3.3 [4 pts]: Which of the following are techniques used to improve the efficiency of solving CSPs?**

- [x] Forward Checking
- [x] Heuristic Variable Ordering (e.g., Minimum Remaining Values heuristic)
- [ ] Alpha-Beta Pruning
- [x] Constraint Propagation (e.g., Arc Consistency algorithms)
- [ ] Hill Climbing

**【中文解答与解析】**
**正确选项：Forward Checking, Heuristic Variable Ordering, Constraint Propagation**

* **Forward Checking (前向检查) - 正确**：每次为变量赋值后，前向检查会立即查看所有与该变量相关联的未赋值变量，并从它们的值域中删除与当前赋值冲突的值，这大大提高了求解效率。
* **Heuristic Variable Ordering (启发式变量排序，例如MRV) - 正确**：通过选择具有最少剩余合法值的变量优先赋值（最受约束变量启发式 MRV），可以更早地发现失败并触发回溯，从而修剪搜索树，提高效率。
* **Alpha-Beta Pruning (Alpha-Beta剪枝) - 错误**：Alpha-Beta剪枝是用于对抗性搜索（如极大极小博弈树，国际象棋等）的优化技术，并不用于求解CSP。
* **Constraint Propagation (约束传播，例如弧一致性算法) - 正确**：像AC-3这样的算法通过在变量对之间反复传播约束来剔除无效值，能在搜索开始前或搜索过程中大幅削减搜索空间。
* **Hill Climbing (爬山法) - 错误**：爬山法属于局部搜索优化算法。虽然有针对CSP的局部搜索变体（如最小冲突启发式 Min-Conflicts），但“爬山法”本身并不是针对经典CSP回溯搜索以提高效率的标准配套技术。

### 4.1 [4 pts]: If the agent uses Q-learning, what will be the updated Q-values after the first episode, assuming the agent:

# Question 5 [10 pts total]

### 5.1 [5 pts]: Define what is meant by exploration and exploitation and explain why it is a crucial aspect in reinforcement learning.

**Answer / 详细解答:**

* **Exploration (探索):** Involves the agent selecting actions that are not necessarily the best according to its current knowledge. The goal is to discover new states, learn more about the environment, and potentially find better actions that yield higher long-term rewards.
    * *中文解释*: 智能体尝试那些在当前看来并非最优的动作，目的是探索未知的状态和环境规律，从而有可能发现能带来更高长期回报的新策略。
* **Exploitation (利用):** Involves the agent selecting the action that is currently known to yield the highest expected reward based on its existing knowledge (e.g., choosing the action with the highest Q-value).
    * *中文解释*: 智能体根据已经学到的知识，贪婪地选择当前已知能带来最大预期回报的动作（例如选择Q值最高的动作），以最大化短期收益。
* **Why it is crucial (The Exploration-Exploitation Dilemma / 为什么它是核心关键):** It is crucial because an agent must balance these two competing objectives. If an agent *only exploits*, it may get stuck in a sub-optimal local maximum because it never discovers potentially better strategies that are currently unknown. Conversely, if it *only explores*, it will continuously act randomly and fail to accumulate rewards by using what it has already learned. Effective RL algorithms (like $\epsilon$-greedy) balance this trade-off to ensure the agent eventually learns the global optimal policy while still gathering rewards.
    * *中文解释*: 这是强化学习中经典的“探索-利用窘境”。如果只是一味地“利用”，智能体极易陷入局部最优解，因为它永远不会去尝试那些可能更好的未知动作；如果只是一味地“探索”，智能体就等于在做随机运动，无法利用已学到的经验来最大化收益。因此，合理平衡两者的关系（例如使用 $\epsilon$-贪心策略），是确保智能体既能收敛到全局最优策略，又能获取有效回报的关键所在。

### 5.2 [5 pts]: Discuss the conditions under which Q-learning converges to the optimal policy in stochastic environments. Identify and explain at least two potential issues that may arise.

**Answer / 详细解答:**

**Conditions for Convergence (收敛的理论条件):**
For tabular Q-learning to converge to the optimal Q-values (and thus the optimal policy) in stochastic environments, the following conditions must be met (often referred to as Robbins-Monro conditions):
1.  **Infinite Exploration (充分探索):** Every state-action pair $(s, a)$ must be visited and updated infinitely often.
2.  **Appropriate Learning Rate Decay (学习率合理衰减):** The learning rate $\alpha$ must decrease over time such that it satisfies $\sum_{t=0}^{\infty} \alpha_t = \infty$ (ensuring it can reach any value/overcome initial conditions) and $\sum_{t=0}^{\infty} \alpha_t^2 < \infty$ (ensuring it eventually settles and the variance of updates goes to zero).
    * *中文解释*: Q-learning收敛需要满足两个主要条件：一是所有的状态-动作对必须被无限次地访问（即不能有遗漏的状态）；二是学习率 $\alpha$ 必须随时间逐渐衰减，既要保证衰减得不够快以至于停止学习（总和为无穷大），又要保证衰减得足够快以确保最终稳定（平方和为有限值）。

**Potential Issues (可能出现的两个主要问题):**

1.  **Curse of Dimensionality / Large State Spaces (维度灾难 / 状态空间过大):**
    * *Explanation:* Standard Q-learning uses a table to store values for every $(s, a)$ pair. In complex environments (like continuous control or high-resolution images), the state-action space is astronomically large or infinite. The algorithm cannot store the table in memory, nor can it visit every state-action pair infinitely often, causing convergence to fail. (This is usually mitigated by using function approximators like Deep Q-Networks / DQN).
    * *中文解释*: 经典的Q-learning使用表格记录Q值。如果环境的状态或动作空间非常大（或者是连续空间），不仅内存无法存储，且根本不可能满足“访问所有状态无限次”的条件，导致算法失效。这种问题通常需要引入深度神经网络（DQN）来近似拟合。
2.  **Maximization Bias / Overestimation (最大化偏差 / 高估问题):**
    * *Explanation:* The Q-learning update rule uses the $\max$ operator to estimate the value of the next state: $\max_{a'} Q(s', a')$. Because the Q-values are estimates that contain noise or statistical errors, taking the maximum over these noisy estimates systematically overestimates the true expected reward. This can lead the agent to learn sub-optimal policies. (This issue led to the development of Double Q-learning).
    * *中文解释*: Q-learning在更新公式中使用了 $\max$ 操作符来估计下一个状态的最大价值。由于初期Q值估计存在噪声和方差，总是取最大值会导致系统性地“高估”某些状态的真实回报。这会误导智能体陷入次优策略（解决此问题的经典方法是使用 Double Q-learning）。

# Question 6 [14 pts total]

### 6.1.1 [3 pts]: Explain how the Perceptron algorithm updates its weights during training. Include the mathematical formula for the weight update rule and describe each term in the formula.

**【中文解答与解析】**

感知机（Perceptron）算法通过逐个样本检查预测结果来更新权重。对于每个训练样本，它首先计算净输入（特征与权重的点积加上偏置），然后应用阶跃函数（Step function）得出离散的预测类别（例如 1 或 -1，或者 1 或 0）。如果预测类别与真实标签不符，算法就会朝着减少该误差的方向更新权重和偏置；如果预测正确，则权重保持不变。

**数学公式 (Mathematical Formula):**
权重更新公式为：
$$w^{(new)} = w^{(old)} + \Delta w$$
其中权重的变化量 $\Delta w$ 的计算方式为：
$$\Delta w = \eta (y - \hat{y}) x$$

偏置的更新公式为：
$$b^{(new)} = b^{(old)} + \Delta b$$
其中偏置的变化量 $\Delta b$ 为：
$$\Delta b = \eta (y - \hat{y})$$

**各项术语解释 (Description of terms):**
* **$w$**: 模型当前的权重向量 (Weight vector)。
* **$x$**: 当前训练样本的输入特征向量 (Input features)。
* **$b$**: 偏置项 (Bias)。
* **$\eta$**: 学习率 (Learning rate)，通常是一个介于 0.0 和 1.0 之间的小常数，用于控制权重更新的步长。
* **$y$**: 当前样本的真实标签 (Target/True label)。
* **$\hat{y}$**: 模型预测出的类别标签 (Predicted label)，即 $\hat{y} = \text{step\_function}(w \cdot x + b)$。

### 6.1.2 [4 pts]: Given the following data point and model parameters:
* Input features: x = [2, -1]
* Current weights: w = [0.5, -0.5]
* Bias: b = 0.0
* Target label: y = 1
* Learning rate: $\eta$ = 0.1

Calculate the model's prediction for this data point. If the prediction is incorrect, update the weights and bias using the Perceptron rule. Show all calculations step-by-step.

**【中文解答与解析】**

**第一步：计算净输入 (Net Input, $z$)**
$$z = (w \cdot x) + b = (w_1 x_1 + w_2 x_2) + b$$
$$z = (0.5 \times 2) + (-0.5 \times -1) + 0.0$$
$$z = 1.0 + 0.5 = 1.5$$

**第二步：计算预测值 (Prediction, $\hat{y}$)**
感知机使用阶跃函数。通常，如果 $z \ge 0$，则预测 $\hat{y} = 1$；如果 $z < 0$，则预测 $\hat{y} = -1$ (或 $0$)。
因为 $z = 1.5 \ge 0$，所以模型的预测值为：
$$\hat{y} = 1$$

**第三步：检查并更新参数 (Check and Update)**
真实的标签是 $y = 1$。
因为预测值 $\hat{y}$ 等于真实标签 $y$ ($1 = 1$)，所以预测是**正确**的。
误差为：$(y - \hat{y}) = 1 - 1 = 0$
因此，权重和偏置的更新量均为 $0$。
$$\Delta w = 0.1 \times 0 \times [2, -1] = [0, 0]$$
$$\Delta b = 0.1 \times 0 = 0$$

**结论：**
因为预测正确，模型不需要进行更新。
**最终权重**: $w = [0.5, -0.5]$
**最终偏置**: $b = 0.0$

### 6.2.1 [3 pts]: Explain how Adaline (Adaptive Linear Neuron) differs from the Perceptron in terms of:
* The type of function used to calculate errors.
* The weight update rule.
* Convergence behavior.

**【中文解答与解析】**

Adaline（自适应线性神经元）是对感知机的改进，它们的主要区别如下：

1.  **误差计算函数 (Type of function used to calculate errors):**
    * **Perceptron (感知机)**: 基于经过**阶跃函数**（Step function）处理后的**离散预测类别**（$\hat{y}$）来计算误差，即计算 $(y - \hat{y})$。它只关心分类是对还是错。
    * **Adaline**: 基于应用阶跃函数之前的**连续线性激活函数**（即净输入 $z = w \cdot x + b$）来计算误差，即计算 $(y - z)$。它不仅关心是否正确，还关心距离目标的偏差程度。

2.  **权重更新规则 (The weight update rule):**
    * **Perceptron (感知机)**: 只有在发生错误分类时才更新权重。
    * **Adaline**: 使用**梯度下降法**（Gradient Descent）来最小化连续的误差平方和（Sum of Squared Errors, SSE）代价函数。无论样本最终的类别预测是否正确，只要净输入 $z$ 不完全等于目标标签 $y$，权重就会根据公式 $\Delta w = \eta (y - z) x$ 持续进行微调。

3.  **收敛行为 (Convergence behavior):**
    * **Perceptron (感知机)**: 只有当训练数据集是**完全线性可分**时才能保证收敛。如果数据不是线性可分的，感知机的权重更新会永远震荡下去，无法停止。
    * **Adaline**: 即使数据集不是完美线性可分的，只要学习率设置得足够小，Adaline 也能通过梯度下降收敛到代价函数的**全局最小值**（Global minimum），找到一条最佳拟合的决策边界。

### 6.2.2 [4 pts]: Consider the same data point as in Part 6.1 with the Adaline algorithm:

Calculate the model's net input (z) for this data point, compute the error (y - z). Update the weights and bias using the Adaline weight update rule. Show all calculations step-by-step.

### 7.1 [4 pts]: Using the Euclidean Distance as the distance metric, calculate the distance from P7 to all other points in the dataset (P1 through P6). Show your calculations.

**【中文解答与解析】**

欧几里得距离（Euclidean Distance）的计算公式为：
$$d(p, q) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

这里我们将“Age”作为 $x$，“Income”作为 $y$（为了计算方便，Income直接提取数值部分，即55, 60等）。目标点 P7 的坐标为 $(37, 75)$。

* **P7 到 P1 的距离:**
    $$d(P1, P7) = \sqrt{(25 - 37)^2 + (55 - 75)^2} = \sqrt{(-12)^2 + (-20)^2} = \sqrt{144 + 400} = \sqrt{544} \approx 23.32$$

* **P7 到 P2 的距离:**
    $$d(P2, P7) = \sqrt{(30 - 37)^2 + (60 - 75)^2} = \sqrt{(-7)^2 + (-15)^2} = \sqrt{49 + 225} = \sqrt{274} \approx 16.55$$

* **P7 到 P3 的距离:**
    $$d(P3, P7) = \sqrt{(35 - 37)^2 + (70 - 75)^2} = \sqrt{(-2)^2 + (-5)^2} = \sqrt{4 + 25} = \sqrt{29} \approx 5.39$$

* **P7 到 P4 的距离:**
    $$d(P4, P7) = \sqrt{(40 - 37)^2 + (80 - 75)^2} = \sqrt{3^2 + 5^2} = \sqrt{9 + 25} = \sqrt{34} \approx 5.83$$

* **P7 到 P5 的距离:**
    $$d(P5, P7) = \sqrt{(45 - 37)^2 + (90 - 75)^2} = \sqrt{8^2 + 15^2} = \sqrt{64 + 225} = \sqrt{289} = 17.00$$

* **P7 到 P6 的距离:**
    $$d(P6, P7) = \sqrt{(50 - 37)^2 + (90 - 75)^2} = \sqrt{13^2 + 15^2} = \sqrt{169 + 225} = \sqrt{394} \approx 19.85$$

### 7.2 [4 pts]: If k = 3, classify P7 using the K-Nearest Neighbors (KNN) algorithm.

**【中文解答与解析】**

KNN算法的核心是找出距离目标点最近的 $k$ 个点，并由这些点的类别进行“多数表决”（Majority Voting）。

1.  **找出距离最近的 3 个点 ($k=3$)：**

### 7.3 [4 pts]: Explain one potential drawback of the KNN algorithm when dealing with datasets that have: 1. Very large numbers of features (high dimensionality). 2. Imbalanced class distributions. Propose one strategy to address each drawback.

**【中文解答与解析】**

**1. 高维特征数据集 (Very large numbers of features / High dimensionality)**
* **Drawback (缺点解释):** 当特征数量非常大时，KNN 会遭遇“维度灾难”（Curse of Dimensionality）。在高维空间中，所有数据点之间的距离会趋于相似（即最近邻和最远邻的距离差异变得非常小），导致“最近邻”的概念失效，预测能力显著下降。此外，高维度会使得距离计算的计算量呈指数级增加，导致算法运行极其缓慢。
* **Strategy (应对策略):** 使用**降维技术**（Dimensionality Reduction）。例如，在应用 KNN 之前，先使用主成分分析（PCA，Principal Component Analysis）提取最重要的特征组合，或者使用特征选择（Feature Selection）剔除无关紧要的特征，从而降低数据的维度。

**2. 类别不平衡数据集 (Imbalanced class distributions)**
* **Drawback (缺点解释):** 在类别严重不平衡的情况下（例如 90% 的样本是A类，10% 是B类），KNN 的“多数表决”机制会产生严重偏见。对于一个新的测试点，它的 $k$ 个最近邻居很有可能单纯因为A类样本的数量极其庞大而全都是A类。这会导致模型过度倾向于预测多数类，而无法准确识别少数类。
* **Strategy (应对策略):** 使用**距离加权 KNN**（Distance-Weighted KNN）。改变默认的平等投票机制，赋予距离更近的邻居更高的投票权重（例如权重设为距离的倒数 $1/d$）。这样，即使周围多数类的数量多，但只要少数类离目标点足够近，其高权重也能扳回一城。此外，也可以使用**数据重采样技术**（如 SMOTE 过采样少数类或欠采样多数类）来平衡训练集。
