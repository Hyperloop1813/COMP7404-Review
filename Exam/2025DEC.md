## **Section 1 [20 pts total]**

Indicate whether each of the following statements is true or false by writing T or F in the provided box. Each correct answer earns 1 point, each incorrect answer deducts 1 point, and unanswered questions receive 0 points. The overall minimum for this question is 0 points. No explanations are necessary.

---

**1. Uniform-Cost Search is guaranteed to find an optimal solution provided that all action costs are strictly positive.**

* **答案：** **T (True)**
* **中文解析：** 一致代价搜索 (Uniform-Cost Search) 在所有行动代价都严格为正数（大于零）的情况下，总是按累积代价从小到大的顺序扩展节点。这种机制确保了当目标节点被弹出（扩展）时，它所对应的路径一定是最优解。

**2. A heuristic h(n) is admissible if, for every state n, its estimate is less than or equal to the cost of an optimal path from n to any reachable goal state.**

* **答案：** **T (True)**
* **中文解析：** 这正是可容许启发式 (Admissible heuristic) 的标准定义。可容许启发式要求对任意状态 $n$，它的启发式估计值永远保持乐观，即绝对不会超过从该状态 $n$ 到达目标的实际最优路径代价。

**3. If a heuristic is admissible, it must also satisfy the triangle inequality h(n) <= c(n,n') + h(n') for every successor n', where c(n,n') denotes the step cost of moving from state n to state n'.**

* **答案：** **F (False)**
* **中文解析：** 题目中描述的三角不等式是**一致性 (Consistency)** 的定义，而不是可容许性的定义。一个启发式函数可以是可容许的，但不具备一致性（尽管在实践中大多数可容许启发式也是一致的）。逻辑关系是：一致性一定能推导出可容许性，但可容许性不能推导出一致性。

**4. Greedy best-first search is guaranteed to find an optimal solution whenever it uses an admissible heuristic.**

* **答案：** **F (False)**
* **中文解析：** 贪婪最佳优先搜索 (Greedy best-first search) 的评估函数仅依赖于启发式，即 $f(n) = h(n)$。它完全忽略了已经花费的代价 $g(n)$，因此容易陷入局部最优或死胡同。只有结合了已知代价的 A* 搜索 ($f(n) = g(n) + h(n)$) 在使用可容许启发式时，才能保证找到最优解。

**5. Enforcing arc consistency in a CSP can eliminate some values from variable domains and may detect that the CSP has no solution, even before any variable is fully assigned.**

* **答案：** **T (True)**
* **中文解析：** 强制执行弧一致性 (Arc consistency) 是一种在实际赋值前进行的约束传播技术。它通过检查变量之间的二元约束来剔除值域中不可能合法的值。如果在这个预处理或传播过程中某个变量的值域被削减为空，就能提前断定该约束满足问题 (CSP) 无解。

**6. The Minimum Remaining Values (MRV) heuristic for variable ordering selects the variable that currently has the largest number of legal values left in its domain.**

* **答案：** **F (False)**
* **中文解析：** 最小剩余值 (MRV - Minimum Remaining Values) 启发式，顾名思义，选择的是当前值域中剩余合法值**最少**的变量，而不是最多的变量。这也被称为“最受约束变量”启发式，其目的是尽早触发失败以大幅减少搜索树的分支。

**7. In a zero-sum game, adding the same constant to all terminal utilities for both players does not change which strategies are optimal under minimax.**

* **答案：** **T (True)**
* **中文解析：** 在零和博弈中，给所有终结状态的效用值加上（或乘上一个正数）一个固定的常数，属于严格的单调变换。这种线性平移不会改变任何极小极大 (Minimax) 决策节点的相对优劣顺序，因此最优策略保持完全不变。

**8. Alpha-beta pruning preserves the correct minimax value at the root, regardless of how the game tree's children are ordered.**

* **答案：** **T (True)**
* **中文解析：** Alpha-beta 剪枝在数学上是绝对安全的。子节点的评估顺序只会显著影响剪枝的**效率**（即能剪掉多少无用的分支），但它绝对不会改变根节点最终计算出的极小极大值。

**9. In a discounted MDP, using a discount factor very close to 0 makes the agent focus mainly on immediate rewards rather than long-term returns.**

* **答案：** **T (True)**
* **中文解析：** 在马尔可夫决策过程 (MDP) 中，折扣因子 $\gamma$ 控制着对未来奖励的重视程度。当 $\gamma$ 非常接近 0 时，未来的奖励在当前看来会被衰减得极其微弱。这就导致智能体变得非常“短视”，其策略会主要为了获取眼前的即时奖励而优化。

**10. For any finite MDP with discount factor 0 <= gamma <= 1, repeatedly applying the Bellman optimality update to all states (value iteration) converges to the optimal value function.**

* **答案：** **F (False)**
* **中文解析：** 值迭代 (Value iteration) 保证收敛的标准前提条件是折扣因子必须严格小于 1，即 $0 \leq \gamma < 1$。如果 $\gamma = 1$（无折扣），除非该 MDP 具有特殊的结构（例如保证能以概率 1 在有限步内到达终止状态，且不包含正收益的循环），否则长期的累积价值可能会发散到无穷大，导致值迭代无法收敛。

**11. In off-policy reinforcement learning, the policy used to generate experience (the behavior policy) must be the same as the policy whose value is being learned (the target policy).**

* **答案：** **F (False)**
* **中文解析：** 这是**同轨策略 (On-policy)** 的定义。**离轨策略 (Off-policy)** 强化学习的定义恰恰相反，它允许用于生成数据的“行为策略 (behavior policy)”与正在评估或优化的“目标策略 (target policy)”不同。例如，Q-learning 就是典型的离轨策略算法，它用 $\epsilon$-greedy 策略去探索环境，但学习的是完全贪婪 (greedy) 策略的最优 Q 值。

**12. Q-learning is a model-based reinforcement learning algorithm because it explicitly learns the transition probabilities T(s,a,s') of the environment.**

* **答案：** **F (False)**
* **中文解析：** Q-learning 是一种**无模型 (Model-free)** 强化学习算法。它直接通过经验更新动作价值函数 (Q-value)，而不需要去学习或估计环境的转移概率模型 $T(s,a,s')$ 或奖励模型 $R(s,a,s')$。

**13. In epsilon-greedy action selection, using a smaller value of epsilon generally leads to more exploitation and less exploration.**

* **答案：** **T (True)**
* **中文解析：** 在 $\epsilon$-greedy（Epsilon-贪婪）策略中，智能体有 $\epsilon$ 的概率随机选择动作（探索 Exploration），有 $1-\epsilon$ 的概率选择当前 Q 值最高的动作（利用/开发 Exploitation）。因此，$\epsilon$ 越小，随机探索的概率就越低，利用已知最优动作的概率就越高。

**14. The Perceptron uses a differentiable activation function, which allows it to be trained using gradient descent.**

* **答案：** **F (False)**
* **中文解析：** 经典的感知机 (Perceptron) 使用的是**阶跃函数 (Step function)** 作为激活函数。阶跃函数在 0 处不可导，在其他地方导数均为 0，因此无法使用标准的梯度下降法进行训练。感知机使用的是专门的感知机更新规则。逻辑回归 (Logistic Regression) 才使用可导的 Sigmoid 函数并通过梯度下降训练。

**15. In logistic regression, the model’s output for a given input is a value between 0 and 1 that can be interpreted as an estimated probability for the positive class.**

* **答案：** **T (True)**
* **中文解析：** 逻辑回归利用 Sigmoid 函数将线性模型的输出映射到 $(0, 1)$ 区间内。这个输出值通常被明确解释为给定输入特征下，样本属于正类 (Positive class) 的后验概率，即 $P(Y=1|X)$。

**16. Increasing the learning rate in gradient descent always speeds up convergence.**

* **答案：** **F (False)**
* **中文解析：** 并非总是如此。适当地增加学习率确实可以加快收敛，但是如果学习率过大，每次更新的步长过长，会导致参数在最优解附近来回震荡，甚至越过最低点导致发散 (Divergence)，反而无法收敛。

**17. KNN has low inference cost because all necessary computations are completed during the training phase, before any query points are classified.**

* **答案：** **F (False)**
* **中文解析：** K近邻算法 (KNN) 是一种典型的“懒惰学习 (Lazy Learning)”。它的训练阶段几乎不需要计算（只是将训练数据存储起来），但它的**推理/测试成本 (Inference cost) 非常高**。因为对于每一个新的查询点，它都需要计算该点到所有训练样本的距离，然后进行排序才能得出结果。

**18. In a trained SVM, removing any non-support vector training example does not change the final decision boundary.**

* **答案：** **T (True)**
* **中文解析：** 支持向量机 (SVM) 的核心特性在于，它的决策边界（超平面）仅仅由少数几个位于边缘上的数据点——即“支持向量 (Support Vectors)”来决定。不在边缘上（即不在间隔边界上或违反间隔）的非支持向量对决策边界没有任何影响，删掉它们完全不会改变训练结果。

**19. A hard-margin SVM can be successfully trained even when the data is not linearly separable.**

* **答案：** **F (False)**
* **中文解析：** 硬间隔 (Hard-margin) SVM 要求所有训练数据必须被无误差地完美线性分开。如果数据本身不是线性可分的（存在噪声或重叠），硬间隔优化的数学模型将无解。处理非线性可分数据必须引入松弛变量，使用**软间隔 (Soft-margin)** SVM，或者使用核技巧 (Kernel trick)。

**20. A fully grown decision tree (grown until all leaves are pure) typically has high variance.**

* **答案：** **T (True)**
* **中文解析：** 完全生长（直到所有叶子节点都只有一种类别的样本，即纯节点）的决策树极易发生**过拟合 (Overfitting)**。它完美记住了训练集的数据细节和噪声，因此偏差 (Bias) 很低，但当应用到未见过的测试数据时，预测结果会非常不稳定，即具有很高的方差 (High variance)。

### Question 1

**Which statement about decision trees is correct?**
a) They always produce linear decision boundaries.
b) They guarantee the globally optimal split at every node.
c) They select splits greedily based on a chosen impurity measure.
d) They inherently prevent overfitting without pruning.

**【正确答案】 c**

**【详细中文解答】**

* **a) 错误**。决策树生成的决策边界通常是正交的、阶梯状的非线性边界，而不是简单的线性边界。
* **b) 错误**。决策树的构建使用的是贪心算法（Greedy Algorithm），它在每个节点上只寻找当前局部的最优划分，不能保证全局最优。
* **c) 正确**。决策树在每个节点处，会根据某种不纯度度量（如基尼系数 Gini Impurity 或 信息熵 Entropy）采用贪心策略来选择最佳分裂特征。
* **d) 错误**。如果不进行剪枝（Pruning），决策树会不断向下分裂直到叶子节点完全纯净，这极其容易导致过拟合（Overfitting），而不是防止过拟合。

### Question 2

**Why does Q-learning not require a model of the environment?**
a) Because it assumes transitions are deterministic.
b) Because it stores the entire transition table.
c) Because it computes values only for terminal states.
d) Because it learns expected returns directly from sampled transitions.

**【正确答案】 d**

**【详细中文解答】**

* **a) 错误**。Q-learning 既可以用于确定性环境，也可以用于随机性环境，它并不假设状态转移是确定性的。

* **c) 错误**。Q-learning 会计算所有被访问状态（不仅是终止状态）的Q值。
* **d) 正确**。Q-learning 是一种无模型（Model-free）的强化学习算法。它通过智能体在环境中交互采样得到的状态转移数据（当前状态、动作、奖励、下一状态）来直接更新和学习期望回报（Q值），因此不需要环境的先验动态模型（即状态转移概率和奖励函数）。

### Question 3

**Which of the following correctly defines the Q-value $Q^*(s,a)$ in reinforcement learning?**
a) The probability of reaching the goal from state s
b) The expected immediate reward only
c) The expected return when taking action a in state s and then following the optimal policy
d) The number of visits to (s,a) during training

**【正确答案】 c**

**【详细中文解答】**

* **a) 错误**。Q值代表的是价值（期望回报），而不是到达目标的概率。
* **b) 错误**。Q值不仅包含即时奖励，还包含未来长期的折扣期望回报。
* **c) 正确**。最优Q值 $Q^*(s,a)$ 的严格定义是：在状态 $s$ 下采取动作 $a$，并且在之后的所有步骤中都遵循最优策略（Optimal Policy）所能获得的期望总回报（Expected Return）。
* **d) 错误**。这是访问计数，不是Q值的定义。

### Question 5

**What is one reason Random Forests reduce overfitting compared to a single decision tree?**
a) Their trees are guaranteed to be shallower.
b) They restrict the number of classes in the data.
c) They reuse the same bootstrap sample for all trees.
d) They average predictions from many de-correlated trees.

**【正确答案】 d**

**【详细中文解答】**

* **a) 错误**。随机森林中的单棵树通常也会生长得很深（甚至不限制深度），并不能保证它们比单棵决策树浅。
* **b) 错误**。随机森林不会限制数据中的类别数量。
* **c) 错误**。随机森林使用的是不同的 Bootstrap 采样数据集来训练每棵树，而不是重用同一个样本，以此来增加树的多样性。
* **d) 正确**。随机森林通过 Bootstrap 抽样和特征随机选择（Bagging的变体），构建出许多相互之间差异较大（去相关 / de-correlated）的决策树。由于单棵树容易过拟合（高方差），将这些树的预测结果进行平均（或多数投票）能够显著降低整体模型的方差，从而减少过拟合。

### Question 6

**In MDPs, what does the Bellman policy evaluation equation compute for a fixed policy $\pi$?**
a) The optimal state values
b) The expected return of following $\pi$ from each state
c) The transition probabilities under $\pi$
d) The maximum Q-values over all actions

**【正确答案】 b**

**【详细中文解答】**

* **a) 错误**。计算最优状态价值（$V^*$）用的是贝尔曼最优方程（Bellman Optimality Equation），而不是策略评估方程。
* **b) 正确**。在马尔可夫决策过程（MDP）中，策略评估（Policy Evaluation）的贝尔曼方程用于计算某个固定策略 $\pi$ 下的状态价值函数 $V^\pi(s)$，即从状态 $s$ 出发并始终遵循策略 $\pi$ 所能获得的期望回报。
* **c) 错误**。状态转移概率是环境的固定属性，由模型给出，不是方程计算的结果。
* **d) 错误**。计算最大Q值同样属于贝尔曼最优方程的内容。

### Question 7

**In linear regression, what is the role of the bias term?**
a) It allows the model to fit data that does not pass through the origin.
b) It controls how strongly regularization is applied.
c) It rescales input features to similar ranges.
d) It determines whether the features are linearly dependent.

**【正确答案】 a**

**【详细中文解答】**

* **a) 正确**。在线性回归公式 $y = x^T s + b$ 中（其中 $x$ 代表权重向量，$s$ 代表数据样本特征），$b$ 就是偏置项（bias term），相当于模型在空间中的截距。如果没有偏置项（即 $b=0$），拟合的直线或超平面就会被强制要求必须穿过坐标原点。加入偏置项允许模型整体平移，从而能够准确拟合那些本身分布不经过原点的数据。
* **b) 错误**。控制模型正则化强度的是正则化惩罚系数（例如 L1/L2 正则化中的 $\lambda$ 参数），而不是偏置项。
* **c) 错误**。将输入特征缩放到相似的数值范围是数据预处理中“特征缩放”（Feature Scaling，如归一化或标准化）的任务，偏置项没有这个功能。
* **d) 错误**。特征之间是否存在线性相关性，是由数据集本身的内在结构和方差决定的，模型中的偏置项无法决定或改变数据的线性相关性。

### Question 8

**For $A*$ search, when does using a consistent heuristic guarantee that no node needs to be re-expanded?**
a) Only when all actions have the same cost
b) Only when the search graph is acyclic
c) Always, because consistent heuristics ensure monotonicity
d) Only when the branching factor is at least 2

**【正确答案】 c**

**【详细中文解答】**

* **a、b、d) 错误**。一致性启发式的保证不依赖于动作代价是否相同、图是否无环，也不依赖于分支因子。
* **c) 正确**。在 A* 图搜索（Graph Search）中，如果启发式函数是一致的（Consistent / Monotonic），它就满足三角不等式：$h(n) \le c(n, a, n') + h(n')$。这保证了沿着任何路径 $f(n)$ 的值是单调不减的（Monotonicity）。因此，当一个节点第一次被移出优先队列（被扩展）时，A* 算法就已经找到了到达该节点的最短路径，之后无需再重新扩展该节点。

### Question 9

**Which optimization method updates model parameters using only a subset of the training data at each step?**
a) Batch Gradient Descent
b) Mini-Batch Gradient Descent
c) Newton’s Method
d) Coordinate Descent

**【正确答案】 b**

**【详细中文解答】**

* **a) 错误**。批量梯度下降（Batch Gradient Descent）在每一步更新时使用**所有**的训练数据。
* **b) 正确**。小批量梯度下降（Mini-Batch Gradient Descent）在每次迭代更新参数时，仅抽取训练数据的一个子集（即一个 Mini-batch）来计算梯度。这平衡了计算效率和梯度更新的稳定性。
* **c) 错误**。牛顿法是一种二阶优化方法，通常也是基于整个数据集（或函数整体）来计算海森矩阵和梯度的。
* **d) 错误**。坐标下降法每次仅沿一个坐标方向（即一个参数）进行优化，与使用多少训练数据子集无关。

### Question 10

**Why is feature scaling important when using KNN?**
a) It reduces the number of neighbors needed.
b) It guarantees that the classes become linearly separable.
c) It prevents features with larger numeric ranges from dominating the distance metric.
d) It ensures that distances between points become uniform.

**【正确答案】 c**

**【详细中文解答】**

* **a) 错误**。邻居数量（K值）是人为设定的超参数，特征缩放并不能减少所需的邻居数量。
* **b) 错误**。特征缩放不会改变数据的内在拓扑结构或线性可分性。
* **c) 正确**。K近邻算法（KNN）主要依赖距离度量（如欧氏距离）来寻找最近的样本。如果某个特征的值域非常大（例如 0 到 10000），而另一个特征的值域非常小（如 0 到 1），那么计算距离时，值域大的特征将完全主导距离计算结果。特征缩放（如标准化或归一化）能够让所有特征在同等尺度下参与计算，防止某一特征主导。
* **d) 错误**。缩放并不会让点与点之间的距离变得完全“统一”或一致，只是统一了各特征维度的量纲。

### 最终全部代码及中文注释

```python
import collections


def bfs_distances(graph, start_node):
    # 初始化 BFS 队列：从起点开始搜索。
    # deque 支持从左端高效弹出节点，适合实现先进先出的 BFS 队列。
    frontier = collections.deque([start_node])

    # 初始化已探索集合：起点一开始就视为已经发现，避免之后被重复加入队列。
    explored_set = {start_node}

    # 初始化距离字典：起点到自己的距离为 0。
    distances = {start_node: 0}

    # 只要队列中还有待扩展节点，就继续进行 BFS。
    while frontier:
        # 取出队列最左端的节点，保证按发现顺序逐层扩展。
        current = frontier.popleft()

        # 遍历当前节点的所有邻居。
        # graph.get(current, []) 可以避免 current 不在字典中时发生 KeyError。
        for neighbor in graph.get(current, []):
            # 如果邻居还没有被发现，说明这是第一次到达它。
            # 在无权图 BFS 中，第一次到达某节点时的距离就是最短距离。
            if neighbor not in explored_set:
                # 立即标记为已探索，防止同一节点被重复加入队列。
                explored_set.add(neighbor)

                # 邻居距离 = 当前节点距离 + 当前边的 1 步。
                distances[neighbor] = distances[current] + 1

                # 将新发现的邻居加入队列，等待后续扩展它的邻居。
                frontier.append(neighbor)

    # 返回所有从起点可达节点的最短距离。
    return distances


example_graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': []
}

# 设置 BFS 的起点。
start = 'A'

# 计算从起点到所有可达节点的最短边数。
dist = bfs_distances(example_graph, start)

# 输出结果，例如：{'A': 0, 'B': 1, 'C': 1, 'D': 2}
print(dist)
```

### 题目中文解析

这道题考查 Q-learning 的 TD 更新公式：

```python
Q(s, a) <- Q(s, a) + alpha * (r + gamma * max_a' Q(s', a') - Q(s, a))
```

其中：

* `state` 是当前状态 $s$。
* `action` 是当前动作 $a$。
* `next_state` 是执行动作后到达的下一状态 $s'$。
* `reward` 是从当前状态转移到下一状态得到的即时奖励 $r$。
* `max_a' Q(s', a')` 必须查看的是“下一状态”的所有动作 Q 值，而不是“当前状态”的 Q 值。

原代码的错误行是：

```python
max_next_q = np.max(q_table[state, :])
```

这行错误地用当前状态 `state` 计算未来最优价值，相当于让 Q-learning 在更新时看错了状态。正确逻辑应该是在 `next_state` 上取最大 Q 值：

```python
max_next_q = np.max(q_table[next_state, :])
```

因为目标状态 `GOAL_STATE` 的 Q 值初始化为 0，且到达目标后 episode 会结束，所以当 `next_state` 是终止状态时，`np.max(q_table[next_state, :])` 会自然得到 0，不会继续错误地累加未来奖励。

### 最终修改正确全部代码及中文注释

```python
import numpy as np
import random


# 环境规模：一共有 5 个状态，编号为 0, 1, 2, 3, 4。
# 每个状态下有 2 个动作：0 表示向左，1 表示向右。
NUM_STATES = 5
NUM_ACTIONS = 2

# 定义起点、目标状态和陷阱状态。
# agent 每一轮从 START_STATE 出发，目标是到达 GOAL_STATE。
START_STATE = 0
GOAL_STATE = 4
PIT_STATE = 2

# 终止状态列表：到达目标状态后，本轮 episode 结束。
TERMINAL_STATES = [GOAL_STATE]

# Q-learning 的超参数。
# LEARNING_RATE 控制每次更新吸收新信息的比例。
# DISCOUNT_FACTOR 控制未来奖励的重要程度。
# EPSILON 控制 epsilon-greedy 中随机探索的概率。
LEARNING_RATE = 0.1
DISCOUNT_FACTOR = 0.9
NUM_EPISODES = 500
EPSILON = 0.1

# Q 表：行表示状态，列表示动作。
# q_table[s, a] 表示在状态 s 执行动作 a 的估计价值。
q_table = np.zeros((NUM_STATES, NUM_ACTIONS))


def step(state, action):
    # 如果当前已经在终止状态，继续停留在该状态，并且没有额外奖励。
    if state in TERMINAL_STATES:
        return state, 0

    # 根据动作计算下一状态。
    # 动作 0 向左移动，不能小于状态 0。
    if action == 0:
        next_state = max(0, state - 1)
    # 动作 1 向右移动，不能超过最后一个状态 NUM_STATES - 1。
    else:
        next_state = min(NUM_STATES - 1, state + 1)

    # 根据到达的下一状态设置奖励。
    # 到达目标给正奖励，到达陷阱给强负奖励，普通移动给小负奖励。
    if next_state == GOAL_STATE:
        reward = 10
    elif next_state == PIT_STATE:
        reward = -5
    else:
        reward = -1

    # 返回环境转移结果：下一状态和即时奖励。
    return next_state, reward


print("Starting Training...")

# 重复训练多个 episode，让 Q 表逐渐收敛。
for episode in range(NUM_EPISODES):
    # 每一轮都从起点重新开始。
    state = START_STATE
    done = False

    # 当前 episode 未结束时持续与环境交互。
    while not done:
        # epsilon-greedy 动作选择：
        # 以 EPSILON 的概率随机探索，否则选择当前 Q 值最大的动作。
        if random.random() < EPSILON:
            action = random.randint(0, NUM_ACTIONS - 1)
        else:
            action = int(np.argmax(q_table[state, :]))

        # 执行动作，得到下一状态和即时奖励。
        next_state, reward = step(state, action)

        # 正确的 Q-learning 目标要使用下一状态 next_state 的最大 Q 值。
        # 原错误代码用了 q_table[state, :]，那会错误地查看当前状态。
        max_next_q = np.max(q_table[next_state, :])

        # TD target = 即时奖励 + 折扣后的下一状态最优未来价值。
        td_target = reward + DISCOUNT_FACTOR * max_next_q

        # TD error = 目标值 - 当前估计值。
        td_error = td_target - q_table[state, action]

        # 用 TD error 更新当前状态-动作对的 Q 值。
        q_table[state, action] = q_table[state, action] + LEARNING_RATE * td_error

        # 状态前进到下一状态。
        state = next_state

        # 如果到达终止状态，则结束本轮 episode。
        if state in TERMINAL_STATES:
            done = True

print("Training finished.")
print("Learned Q-table (rounded):")
print(np.round(q_table, 2))
```

其中：

* `s` 是当前状态，`a` 是当前动作。
* `r` 是执行动作后得到的即时奖励。
* `s'` 是下一状态。

```text
Q(S0, A0) = 0 + 0.5 * [3 + 0.8 * 0 - 0]

          = 1.5
```

```text
Q(S1, A0) = 0 + 0.5 * [10 + 0.8 * 0 - 0]
          = 0.5 * 10
          = 5
```

因此，第一轮 episode 结束后的 Q 值为：

```text

Q(S2, A0) = 0
```

```text
          = 2.5
```

第三步：从 S1 执行 A1，到达终止状态 S3，奖励为 +4。

因为 S3 是终止状态：

```text
max Q(S3, a') = 0
```

更新：

```text
Q(S1, A1) = 0 + 0.5 * [4 + 0.8 * 0 - 0]
          = 2
```

没有被本轮访问到的 Q 值保持不变。因此，第二轮 episode 结束后的 Q 值为：

```text
Q(S0, A0) = 1.5
Q(S0, A1) = 2.5
Q(S1, A0) = 5
Q(S1, A1) = 2
Q(S2, A0) = 2.5
Q(S2, A1) = 0
```

#### 5.3 epsilon = 0 时的贪心动作选择

当 `epsilon = 0` 时，epsilon-greedy 策略不再随机探索，而是每次都选择当前状态下 Q 值最大的动作。

根据 5.2 的结果：

```text
S0: Q(S0, A0) = 1.5, Q(S0, A1) = 2.5
S1: Q(S1, A0) = 5,   Q(S1, A1) = 2
S2: Q(S2, A0) = 2.5, Q(S2, A1) = 0
```

所以 agent 会选择：

```text
在 S0 选择 A1，因为 2.5 > 1.5。
在 S1 选择 A0，因为 5 > 2。
在 S2 选择 A0，因为 2.5 > 0。
```

最终答案：

```text
S0 -> A1
S1 -> A0
S2 -> A0
```
