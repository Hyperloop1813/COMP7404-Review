# Section 1

### 1.1
**Original Statement:** Depth-first search is guaranteed to find the optimal solution for any search problem.
**Answer:** **False (F)**
**中文解答：** 错误。深度优先搜索 (DFS) 是不保证最优的 (not optimal)。它只要找到一条到达目标节点的路径就会停止，而不会去比较这是否是代价最小（或路径最短）的最优解。

### 1.2
**Original Statement:** The time complexity of A* search is $O(b^d)$ in the worst case, where $b$ is the branching factor and $d$ is the depth of the goal node.
**Answer:** **True (T)**
**中文解答：** 正确。在最坏的情况下（例如，启发式函数毫无用处 $h(n)=0$，且所有边的代价相同，此时 A* 退化为广度优先搜索 BFS），A* 算法需要扩展目标节点深度 $d$ 之前的所有节点，其时间复杂度为指数级的 $O(b^d)$。

### 1.3
**Original Statement:** The greedy best-first search algorithm always chooses the node with the highest heuristic value.
**Answer:** **False (F)**
**中文解答：** 错误。贪婪最佳优先搜索（Greedy Best-First Search）的目标是尽可能快地到达目标节点，因此它会选择启发式值 $h(n)$ **最小**的节点进行扩展，因为 $h(n)$ 预估的是从当前节点到目标节点的剩余代价，代价越小越好。

### 1.4
**Original Statement:** The time complexity of greedy best-first search is $O(b^m)$ in the worst case, where $b$ is the branching factor and $m$ is the maximum depth of the search tree.
**Answer:** **True (T)**
**中文解答：** 正确。在最坏的情况下（例如启发式函数具有误导性），贪婪最佳优先搜索可能会沿着错误的路径一直向下扩展直到树的最大深度 $m$，其时间复杂度和空间复杂度都会达到 $O(b^m)$，类似于深度优先搜索的最坏情况。

### 1.5
**Original Statement:** Depth-limited search is a variant of depth-first search that limits the depth of the search to avoid infinite loops.
**Answer:** **True (T)**
**中文解答：** 正确。深度受限搜索 (Depth-Limited Search) 就是为了解决 DFS 在无限状态空间或有环图中可能陷入无限循环的问题而提出的。它通过预设一个深度界限 (depth limit $l$)，当搜索达到该深度时就强制回溯。

### 1.6
**Original Statement:** Uniform-cost search is a type of informed search algorithm that uses a heuristic function to guide the search towards the goal node.
**Answer:** **False (F)**
**中文解答：** 错误。一致代价搜索 (Uniform-Cost Search, UCS) 是一种**无信息搜索 (Uninformed Search)** 算法（也称盲目搜索）。它仅仅依赖于从起点到当前节点的实际累积代价 $g(n)$，而不使用任何启发式预估函数 $h(n)$ 来指引方向。

### 1.7
**Original Statement:** The backtracking search algorithm is a complete algorithm for solving any CSP.
**Answer:** **True (T)** *(注：通常在基础AI课程中认定为True，前提是假设有限变量和有限值域)*
**中文解答：** 正确。回溯搜索 (Backtracking Search) 实际上是用于约束满足问题 (CSP) 的深度优先搜索。对于具有**有限离散值域**的 CSP，回溯搜索最终会系统地探索完所有可能的赋值组合，因此它是完备的（Complete），即如果有解必定能找到，无解也能在有限步内确认。

### 1.8
**Original Statement:** The arc consistency algorithm reduces the domain of a variable by removing values that violate its constraints with other variables.
**Answer:** **True (T)**
**中文解答：** 正确。弧一致性算法（如 AC-3）的核心思想就是检查变量之间的二元约束（弧）。如果变量 X 的值域中的某个值，无法在相连变量 Y 的值域中找到任何一个满足约束条件的值，那么就会将该值从 X 的值域中剔除，从而缩小搜索空间。

### 1.9
**Original Statement:** The minimum remaining values (MRV) heuristic is used to select the variable that has the most constraints on the remaining variables in a CSP.
**Answer:** **False (F)**
**中文解答：** 错误。MRV (最少剩余值) 启发式是选择其值域中**剩余合法取值最少**的变量。题目中描述的“选择对剩余变量约束最多的变量”是**度启发式 (Degree Heuristic)** 的定义，这两种启发式是不同的概念。

### 1.10
**Original Statement:** The evaluation function in adversarial search algorithms should take into account the opponent's moves as well as the player's moves.
**Answer:** **True (T)**
**中文解答：** 正确。在对抗搜索中，评估函数 (Evaluation Function) 用于在达到深度限制时评估当前非终端状态的优劣。一个好的评估函数必须综合反映棋局的特征，这自然既包括己方的优势（如己方棋子的数量和位置），也包括对手的威胁和优势。

### 1.11
**Original Statement:** The alpha-beta pruning algorithm can be used to solve non-zero-sum games.
**Answer:** **False (F)**
**中文解答：** 错误。Alpha-Beta 剪枝是建立在 Minimax 算法基础上的，而 Minimax 算法的核心假设是博弈是**零和的 (Zero-sum)**（即一方的收益必然等于另一方的损失）。对于非零和博弈（例如囚徒困境），需要使用更一般化的博弈论方法（如寻找纳什均衡）。

### 1.12
**Original Statement:** The minimax search algorithm uses a heuristic function to evaluate the quality of a move.
**Answer:** **False (F)**
**中文解答：** 错误。**纯粹的** Minimax 算法会一直搜索到博弈树的终端节点（游戏结束状态），并使用真实的**效用函数 (Utility Function)**（如赢=+1，输=-1）来评估。只有在面对复杂游戏（如国际象棋）采用**深度受限的 Minimax (Depth-limited Minimax)** 时，由于无法搜索到底，才会使用**启发式评估函数 (Heuristic Evaluation Function)**。通常在严谨的定义题中，这两者是有严格区分的。

### 1.13
**Original Statement:** Minimax search is a complete algorithm for finding the optimal move for a player in a two-player game.
**Answer:** **True (T)**
**中文解答：** 正确。只要博弈树是有限的（即游戏会在有限步内结束），Minimax 算法就能系统地遍历整个树结构，它是完备的，并且在对手也采取最优策略的假设下能找到最优动作。

### 1.14
**Original Statement:** The Q-learning algorithm is guaranteed to converge to the optimal action-value function of an MDP.
**Answer:** **True (T)**
**中文解答：** 正确。Q-learning 是一种异策略时间差分学习算法。在满足一定数学条件（例如每个状态-动作对都被访问无限次，且学习率以适当的方式衰减）的情况下，Q-learning 被理论证明必定会收敛到最优的动作价值函数 $Q^*$。

### 1.15
**Original Statement:** The value iteration algorithm is guaranteed to converge to the optimal value function of an MDP.
**Answer:** **True (T)**
**中文解答：** 正确。价值迭代 (Value Iteration) 基于贝尔曼最优方程。由于贝尔曼更新操作是一个压缩映射 (Contraction Mapping)，根据巴拿赫不动点定理，无论初始价值函数如何设定，价值迭代最终都保证会收敛到唯一的最优价值函数 $V^*$。

### 1.16
**Original Statement:** The policy iteration algorithm is guaranteed to converge to the optimal policy of an MDP.
**Answer:** **True (T)**
**中文解答：** 正确。策略迭代 (Policy Iteration) 交替进行策略评估和策略改进。在有限状态和有限动作的 MDP 中，由于总的确定性策略数量是有限的，且每一步改进都会产生严格等价或更好的策略，因此它保证在有限次迭代后收敛到最优策略。

### 1.17
**Original Statement:** The optimal policy of an MDP is unique.
**Answer:** **False (F)**
**中文解答：** 错误。对于一个 MDP，其最优价值函数 ($V^*$ 或 $Q^*$) 是唯一确定的。但是，**最优策略可能不止一个**。例如，如果在某个状态下向左走和向右走都能得到相同的最大期望回报，那么选择向左的最优策略和选择向右的最优策略并存。

### 1.18
**Original Statement:** The temporal difference (TD) learning algorithm is a model-based reinforcement learning algorithm that learns the value function of an MDP by bootstrapping.
**Answer:** **False (F)**
**中文解答：** 错误。时间差分 (TD) 学习的后半句是对的（它确实通过自举 bootstrapping 来学习价值函数），但前半句错了。TD 学习是一种**无模型 (Model-free)** 的强化学习算法，它不需要知道环境的转移概率和奖励函数（即不需要 MDP 的动态模型）就能直接从经验中学习。

### 1.19
**Original Statement:** In reinforcement learning, the Bellman equation is used to update the policy based on the expected future rewards.
**Answer:** **False (F)**
**中文解答：** 错误。贝尔曼方程 (Bellman Equation) 是用来计算和更新**状态价值 (Value)** 或 **动作价值 (Q-value)** 的，而不是直接用来更新“策略 (Policy)”。策略的更新通常是在得到价值函数之后，通过对价值函数取贪婪 (greedy) 等操作来间接完成的。

### 1.20
**Original Statement:** In reinforcement learning, the agent's goal is to minimize the expected cumulative reward over time.
**Answer:** **False (F)**
**中文解答：** 错误。强化学习的根本目标恰恰相反：智能体 (Agent) 的目标是**最大化 (Maximize)** 随时间推移所获得的预期**累积奖励 (Cumulative Reward)**。

# Section 2: Reinforcement Learning (Self-Driving System)

**题目背景：** 假设你在负责开发特斯拉 Model Q 的自动驾驶系统，并决定使用强化学习。目标是安全快速到达目的地（成功 +1，碰撞或违规 -1）。状态空间包括车辆自身状态和周围车辆状态，动作空间包括加速、刹车和转向。

### 2.1
**Original English Text:**
**2.1 [4 points]:** Discuss the exploration-exploitation tradeoff in the context of this problem, and describe at least two ways to address it. Use at most 4 sentences for your answer.

**中文解析:**
**题目要求：** 在此问题的语境下讨论探索-利用困境（exploration-exploitation tradeoff），并描述至少两种解决方法。（最多 4 句话）

**解答思路：**
1.  **定义困境 (Tradeoff)：** 在自动驾驶中，“利用”意味着依赖当前学到的最优策略（例如走已知的安全路线），而“探索”则意味着尝试未知或冒险的动作（如急转弯或在复杂路况下加速）以寻找可能更优的策略，但这可能会导致碰撞（-1 奖励）。
2.  **解决方法 1 (Method 1)：** $\epsilon$-greedy 策略。智能体以 $1-\epsilon$ 的概率选择当前最优动作（利用），以 $\epsilon$ 的概率随机选择动作（探索），随着时间推移，可以逐渐衰减 $\epsilon$ 的值，使得训练后期偏向于利用。
3.  **解决方法 2 (Method 2)：** 引入探索奖金 (Exploration Bonuses) 或使用上置信界 (UCB, Upper Confidence Bound) 算法。通过对那些被访问次数较少的状态或动作给予额外的虚拟奖励，鼓励系统在保证基本安全的前提下，系统地探索未知状态，而不是纯粹的随机尝试。

---

### 2.2
**Original English Text:**
**2.2 [4 points]:** Consider the scenario where the cost of collision is increased to -10. How would this affect the learning process and the resulting policy? Would you expect any tradeoffs between safety and efficiency? Use at most 4 sentences for your answer.

**中文解析:**
**题目要求：** 假设碰撞的惩罚增加到 -10。这会如何影响学习过程和最终策略？你是否预期在安全性和效率之间存在权衡？（最多 4 句话）

**解答思路：**
1.  **对学习过程和策略的影响：** 显著增加碰撞惩罚会使智能体在学习过程中变得极其保守，它会快速调整策略以绝对避免任何可能导致碰撞的状态，即使这意味着放弃一些潜在的高回报路线。最终学到的策略将是高度防御性的（defensive driving）。
2.  **安全与效率的权衡 (Tradeoffs)：** 必然存在权衡。为了最大限度地保证安全（避免 -10 的严厉惩罚），自动驾驶系统可能会选择更长但更空旷的路线、保持过大的车距、或者在路口过度等待，这会导致到达目的地的平均时间显著增加，从而大幅牺牲了行驶效率（efficiency）。

# Section 3: Machine Learning (Adaline Algorithm for House Pricing)

**题目背景：** 假设你在开发一个机器学习模型，使用 Adaline 算法，根据房屋的面积和位置来预测香港公寓的价格。

### 3.1
**Original English Text:**
**3.1 [4 points]:** Explain how the Adaline algorithm updates the weights of the model during training.

**中文解析:**
**题目要求：** 解释 Adaline 算法在训练期间是如何更新模型权重的。

**解答思路：**
Adaline 算法通过最小化一个连续的代价函数（通常是预测值与真实值之间的均方误差 MSE 或平方和误差 SSE）来更新权重。它使用**梯度下降 (Gradient Descent)** 方法，通过计算代价函数对每个权重的偏导数（梯度），并将权重沿着梯度的反方向移动一小步（步长由学习率控制）。其权重更新规则是基于线性激活函数的连续输出与真实连续标签之间的误差（$\Delta w_j = \eta \sum (y^{(i)} - \phi(z^{(i)})) x_j^{(i)}$），而不是像感知机那样基于分类后的阶跃输出误差。

---

### 3.2
**Original English Text:**
**3.2 [4 points]:** Describe the activation function used in the Adaline algorithm, and explain how it differs from the activation function used in the perceptron algorithm.

**中文解析:**
**题目要求：** 描述 Adaline 算法中使用的激活函数，并解释它与感知机 (Perceptron) 算法中使用的激活函数有何不同。

**解答思路：**
* **Adaline 的激活函数：** Adaline 使用的是**线性激活函数 (Linear Activation Function)**，即 $\phi(z) = z$，其中 $z$ 是输入的净加权和。它的输出是一个连续的实数值。
* **区别 (Difference)：** 感知机算法使用的是**单位阶跃函数 (Unit Step Function)**，它的输出是离散的（通常是 1 或 -1，代表类别）。最核心的区别在于：Adaline 在**计算代价和更新权重**时使用的是连续的线性输出（这使得误差函数可导，能使用梯度下降）；而感知机更新权重依赖的是经过阶跃函数离散化后的分类结果。虽然 Adaline 最终进行分类预测时也会加上一个量化器（如符号函数），但其学习过程是基于连续激活的。

---

### 3.3
**Original English Text:**
**3.3 [4 points]:** Suppose the input data is not normalized. Explain how this could affect the learning process, and describe at least one technique to address this issue.

**中文解析:**
**题目要求：** 假设输入数据没有标准化。解释这会如何影响学习过程，并描述至少一种解决此问题的技术。

**解答思路：**
* **未标准化的影响 (Impact)：** 如果输入特征（例如，面积的数值可能很大如 1000 平方尺，而表示位置的某个特征数值可能很小如 1）尺度差异巨大，会导致损失函数的等高线呈现细长的椭圆形。这会使得梯度下降算法在寻找全局最小值时产生剧烈的震荡（Zig-zagging），导致收敛速度极慢，甚至如果学习率稍大就会无法收敛发散。
* **解决技术 (Technique)：**
    1.  **标准化 (Standardization / Z-score Normalization)：** 将每个特征的数据减去其均值并除以其标准差，使其符合标准正态分布（均值为 0，方差为 1）。
    2.  **最小-最大缩放 (Min-Max Scaling / Normalization)：** 将所有特征的数据线性缩放到固定的范围，通常是 [0, 1] 之间。

# Section 4


**Original English Text:**
You are working on a project that is using a decision tree to predict whether a customer will purchase a product. You have collected a dataset of 1000 customers, each with just one feature: gender. The target variable is a binary variable indicating whether the customer made a purchase. For the following two questions round your answer to three decimal places.

**中文翻译与背景梳理:**
你正在使用决策树预测顾客是否会购买某产品。数据集共 1000 个样本，只有一个特征：性别 (gender)。目标变量是二元变量（购买/未购买）。**要求：以下两题的最终结果保留三位小数。**

---

### 4.1
**Original English Text:**
**4.1 [4 points]:** Compute the Gini impurity for the root node of the decision tree. Assume that 380 customers made a purchase and 620 customers did not. Recall that the Gini impurity is defined as
$$I_G(t) = \sum_{i=1}^{c} p(i|t)(1 - p(i|t)) = 1 - \sum_{i=1}^{c} p(i|t)^2$$
Where $p(i|t)$ is the proportion of the samples that belong to class i for a particular node t.

**中文解析:**
**题目要求：** 计算决策树根节点的基尼不纯度 (Gini Impurity)。已知在 1000 个顾客中，380 人购买了产品，620 人未购买。

**计算步骤：**
1. **明确类别比例 (Proportions):** 根节点 $t$ 包含了所有的 1000 个样本。
   * 购买的比例 $p(\text{purchase}) = \frac{380}{1000} = 0.38$
   * 未购买的比例 $p(\text{no purchase}) = \frac{620}{1000} = 0.62$

2. **代入基尼不纯度公式:**
   $$I_G(root) = 1 - (p(\text{purchase})^2 + p(\text{no purchase})^2)$$
   $$I_G(root) = 1 - (0.38^2 + 0.62^2)$$
   $$I_G(root) = 1 - (0.1444 + 0.3844)$$
   $$I_G(root) = 1 - 0.5288 = 0.4712$$

3. **保留三位小数:** $0.471$

**最终答案 (Answer for 4.1):** **0.471**

---

### 4.2
**Original English Text:**
**4.2 [4 points]:** Compute the information gain of the decision tree that is using gender as the split criterion. Assume that out of the 380 purchases 300 were made by females and out of the 620 non-purchases 600 were male. Recall that the information gain is defined as
$$IG(D_p, f) = I(D_p) - \frac{N_{left}}{N_p} I(D_{left}) - \frac{N_{right}}{N_p} I(D_{right})$$
where
- $I$ is the impurity measure
- $D_p, D_{left}, \text{and } D_{right}$ are the dataset of the parent, left and right notes respectively
- $N_p, N_{left}, \text{and } N_{right}$ are the number of samples for the parent, left and right notes respectively

**中文解析:**
**题目要求：** 计算使用“性别”作为分裂标准时的信息增益 (Information Gain)。已知 380 个购买者中有 300 个是女性；620 个未购买者中有 600 个是男性。
*(注：根据题目给出的公式定义，此处的杂质度量 $I$ 沿用上题定义的基尼不纯度 $I_G$，因此我们计算的是基于基尼不纯度的信息增益，通常也称为 Gini Gain。)*

**计算步骤：**

1. **梳理左右子节点的数据分布：**
   * **左子节点 (假设为女性 Female)：** 购买的女性 = 300 人。
     未购买的女性 = 总未购买人数(620) - 未购买的男性(600) = 20 人。
     女性总数 ($N_{left}$) = 300 + 20 = 320 人。
   * **右子节点 (假设为男性 Male)：** 购买的男性 = 总购买人数(380) - 购买的女性(300) = 80 人。
     未购买的男性 = 600 人。
     男性总数 ($N_{right}$) = 80 + 600 = 680 人。

2. **计算左子节点 (Female) 的基尼不纯度 $I(D_{left})$:**
   * $p(\text{purchase}) = \frac{300}{320} = \frac{15}{16} = 0.9375$
   * $p(\text{no purchase}) = \frac{20}{320} = \frac{1}{16} = 0.0625$
   * $I(D_{left}) = 1 - ( (\frac{15}{16})^2 + (\frac{1}{16})^2 ) = 1 - (\frac{225}{256} + \frac{1}{256}) = 1 - \frac{226}{256} = \frac{30}{256} = 0.1171875$

3. **计算右子节点 (Male) 的基尼不纯度 $I(D_{right})$:**
   * $p(\text{purchase}) = \frac{80}{680} = \frac{2}{17} \approx 0.117647$
   * $p(\text{no purchase}) = \frac{600}{680} = \frac{15}{17} \approx 0.882353$
   * $I(D_{right}) = 1 - ( (\frac{2}{17})^2 + (\frac{15}{17})^2 ) = 1 - (\frac{4}{289} + \frac{225}{289}) = 1 - \frac{229}{289} = \frac{60}{289} \approx 0.207612$

4. **计算信息增益 $IG$:**
   已知父节点的不纯度 $I(D_p) = 0.4712$ (来自题 4.1)。
   $$IG = I(D_p) - (\frac{N_{left}}{N_p} \times I(D_{left})) - (\frac{N_{right}}{N_p} \times I(D_{right}))$$
   $$IG = 0.4712 - (\frac{320}{1000} \times \frac{30}{256}) - (\frac{680}{1000} \times \frac{60}{289})$$
   $$IG = 0.4712 - 0.0375 - (\frac{17}{25} \times \frac{60}{289})$$
   $$IG = 0.4712 - 0.0375 - (\frac{12}{85})$$
   $$IG \approx 0.4712 - 0.0375 - 0.141176$$
   $$IG \approx 0.292524$$

5. **保留三位小数:** $0.293$

**最终答案 (Answer for 4.2):** **0.293**

# Section 6 [8 points total]

**Original English Text:**
Suppose you are working on a project to develop a machine learning model to predict whether a customer will purchase a product based on their demographic and purchase history. You have collected a dataset of 1,000 customers, each with 10 features, and the target variable is a binary variable indicating whether the customer made a purchase (1) or not (0). You split the dataset into a training set of 800 customers and a test set of 200 customers. You train a logistic regression model on the training set, and evaluate the model's performance on the test set using the confusion matrix.

**中文翻译与背景梳理:**
你在开发一个机器学习模型，预测客户是否会购买产品。目标变量是二元的：购买 (1) 或不购买 (0)。测试集包含 200 个客户。你使用混淆矩阵 (Confusion Matrix) 来评估逻辑回归模型在测试集上的性能。

### 6.1
**Original English Text:**
**6.1 [4 points]:** Define the terms true positive, false positive, true negative, and false negative in the context of this binary classification problem.

**中文解析:**
**题目要求：** 在这个特定的二分类问题（预测客户购买行为）的语境下，定义真正例 (TP)、假正例 (FP)、真负例 (TN) 和假负例 (FN)。

**解答：**
* **True Positive (TP, 真正例):** 模型预测该客户**会**购买产品 (1)，且该客户在现实中**确实**购买了产品 (1)。
* **False Positive (FP, 假正例/误报):** 模型预测该客户**会**购买产品 (1)，但该客户在现实中**并没有**购买产品 (0)。
* **True Negative (TN, 真负例):** 模型预测该客户**不会**购买产品 (0)，且该客户在现实中**确实没有**购买产品 (0)。
* **False Negative (FN, 假负例/漏报):** 模型预测该客户**不会**购买产品 (0)，但该客户在现实中**其实**购买了产品 (1)。

### 6.2
**Original English Text:**
**6.2 [4 points]:** Suppose the logistic regression model predicts that 30 customers in the test set will make a purchase, and 170 customers will not make a purchase. In reality, 35 customers actually made a purchase, and 165 customers did not make a purchase. Calculate the values of the true positive rate, false positive rate, true negative rate, and false negative rate.

**中文解析:**
**题目要求：** 已知模型预测购买为 30 人，预测不购买为 170 人。实际购买为 35 人，实际不购买为 165 人。计算真正例率 (TPR)、假正例率 (FPR)、真负例率 (TNR) 和假负例率 (FNR)。

**解答：**
*注意：这是一个典型的“条件不足”题目。题目只给出了预测的边缘分布和实际的边缘分布，**并没有提供任何一个交叉项（如 TP 的具体数值）**。因此无法计算出确切的单一数值，只能给出公式和基于未知变量的表达式。在考试中遇到此类题目，应写出完整推导以证明你理解了概念。*

1.  **已知条件：**
    * 预测正例 (Predicted Positive) = $TP + FP = 30$
    * 预测负例 (Predicted Negative) = $TN + FN = 170$
    * 实际正例 (Actual Positive, P) = $TP + FN = 35$
    * 实际负例 (Actual Negative, N) = $FP + TN = 165$

2.  **指标定义及公式：**
    * **True Positive Rate (TPR / Recall / Sensitivity):** $TPR = \frac{TP}{Actual P} = \frac{TP}{35}$
    * **False Negative Rate (FNR):** $FNR = \frac{FN}{Actual P} = \frac{FN}{35}$
    * **True Negative Rate (TNR / Specificity):** $TNR = \frac{TN}{Actual N} = \frac{TN}{165}$
    * **False Positive Rate (FPR):** $FPR = \frac{FP}{Actual N} = \frac{FP}{165}$

3.  **计算说明：**
    由于缺乏 $TP$ 或任何其他内部单元格的确切数字，我们无法得到最终的标量结果。如果假设模型正确预测了 $x$ 个购买者（即 $TP = x$），那么各项指标的计算结果为：
    * $TPR = \frac{x}{35}$
    * $FPR = \frac{30 - x}{165}$
    * $TNR = \frac{135 + x}{165}$ (因为 $TN = 165 - FP = 165 - (30 - x)$)
    * $FNR = \frac{35 - x}{35}$
    *(注：$0 \le x \le 30$)*
