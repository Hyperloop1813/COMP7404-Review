## Section 1

### Question 1
**The space complexity of Depth-First Search is generally lower than that of Breadth-First Search.**
**【正确答案】 T (True)**
**【详细中文解答】**
深度优先搜索（DFS）的空间复杂度通常远低于广度优先搜索（BFS）。在最坏情况下，假设树的分支因子为 $b$，最大深度为 $m$，DFS 只需要存储当前路径上的节点以及这些节点的未扩展兄弟节点，其空间复杂度为 $O(bm)$。而 BFS 需要将同一层的所有节点放入队列中，最底层可能的节点数为 $b^d$（$d$ 为目标深度），其空间复杂度为指数级的 $O(b^d)$。

### Question 2
**Local search algorithms, like hill climbing, maintain a frontier of nodes to explore multiple paths simultaneously.**
**【正确答案】 F (False)**
**【详细中文解答】**
局部搜索算法（如爬山法 Hill Climbing）通常只在内存中保持一个“当前状态”（Current State）并评估其邻居状态，而不是像 A* 或 BFS 那样维护一个包含多个待探索路径的“边缘集合”（Frontier）。它们只关注局部改进，不保留多条路径，因此空间复杂度极低。

### Question 3
**Constraint Satisfaction Problems (CSPs) are typically solved using search algorithms that explore complete state assignments.**
**【正确答案】 F (False)**
**【详细中文解答】**
约束满足问题（CSP）通常使用探索“部分赋值”（Partial assignments）的搜索算法来解决，比如回溯搜索（Backtracking search）。算法每次为一个未赋值的变量分配一个值，并检查是否违反约束，如果不满足约束则回溯。虽然也有针对完整赋值的局部搜索算法（如最小冲突法 Min-Conflicts），但这并不是 CSP 最“典型”或唯一的搜索策略，经典 CSP 求解器主要依赖部分赋值构建搜索树。

### Question 4
**The Least Constraining Value (LCV) heuristic suggests choosing the value that rules out the most options for neighboring variables.**
**【正确答案】 F (False)**
**【详细中文解答】**
最少约束值（LCV）启发式建议选择那个排除了**最少**（Fewest / Least）邻居变量合法选项的值。它的核心思想是给后续的变量赋值留下尽可能多的空间，从而增加找到解的概率，避免搜索树过早失败。排除最多选项的做法违背了 LCV 的初衷。

### Question 5
**Minimax algorithm assumes that the opponent (MIN player) will always play optimally to minimize the MAX player's score.**
**【正确答案】 T (True)**
**【详细中文解答】**
极大极小算法（Minimax）的根本假设就是处于零和博弈中的对手（MIN 玩家）是绝对理性的，并且总是采取最优策略来最小化 MAX 玩家的收益（即最大化 MIN 玩家自己的收益）。

### Question 6
**Alpha-beta pruning can sometimes change the final minimax value computed at the root compared to a full Minimax search.**
**【正确答案】 F (False)**
**【详细中文解答】**
Alpha-Beta 剪枝是一种无损优化的剪枝技术。它通过维护 $\alpha$ 和 $\beta$ 的边界值，剪除那些注定不会影响最终决策的分支。因此，无论是否发生剪枝，Alpha-Beta 剪枝在根节点计算出的最终 Minimax 评估值与完全展开的 Minimax 搜索结果是绝对一致的。

### Question 7
**In an MDP, the transition function $T(s, a, s')$ specifies the reward obtained when moving from state $s$ to $s'$ via action $a$.**
**【正确答案】 F (False)**
**【详细中文解答】**
在马尔可夫决策过程（MDP）中，转移函数 $T(s, a, s')$（或表示为 $P(s'|s,a)$）定义的是从状态 $s$ 采取动作 $a$ 后转移到状态 $s'$ 的**概率**（Probability）。指定从 $s$ 到 $s'$ 所获得**奖励**的函数是奖励函数 $R(s, a, s')$。

### Question 8
**The optimal policy $\pi^*(s)$ for an MDP is always deterministic, meaning it specifies a single best action for each state.**
**【正确答案】 T (True)**
**【详细中文解答】**
对于任何具有马尔可夫性质和有界奖励的完全可观测 MDP，数学上可以证明始终存在至少一个确定的最优策略（Deterministic Optimal Policy）。也就是说，在状态 $s$ 下，智能体总可以找到一个固定的最优动作，而不需要采取概率性的随机动作。

### Question 9
**Policy Iteration alternates between evaluating the current policy and improving it until convergence.**
**【正确答案】 T (True)**
**【详细中文解答】**
策略迭代（Policy Iteration）的核心算法流程正是在两个步骤间交替进行：1. 策略评估（Policy Evaluation），计算当前策略下各状态的价值；2. 策略改进（Policy Improvement），根据计算出的价值贪心地更新当前策略。这两个步骤不断交替，直到策略不再发生变化（即收敛到最优策略）。

### Question 10
**Solving an MDP (finding the optimal policy) requires the agent to interact with the environment to discover the transition and reward functions.**
**【正确答案】 F (False)**
**【详细中文解答】**
“解决 MDP”通常指的是在**已知**环境的转移函数 $T$ 和奖励函数 $R$ 的情况下，通过规划算法（Planning，如价值迭代或策略迭代）离线计算出最优策略，这不需要与环境互动。如果转移和奖励函数是未知的，需要智能体通过与环境交互来学习策略，这就不再是单纯的求解 MDP 问题，而是强化学习（Reinforcement Learning）的范畴。

### Question 11
**Temporal Difference (TD) learning updates value estimates only at the end of a complete episode.**
**【正确答案】 F (False)**
**【详细中文解答】**
时序差分（TD）学习的核心优势在于它可以进行**增量式更新**（Incremental Update）。在每走一步（即经历一个状态转移）之后，它就会利用自举法（Bootstrapping）基于下一个状态的估计价值来更新当前状态的价值。只有蒙特卡洛方法（Monte Carlo Methods）才需要等到一个完整的 episode 结束后才进行价值更新。

### Question 12
**Using function approximation (like linear features) in Q-learning allows generalization across states but may prevent convergence to the exact optimal Q-values.**
**【正确答案】 T (True)**
**【详细中文解答】**
在强化学习中，使用函数近似（如线性特征或神经网络）可以帮助智能体在庞大的状态空间中进行泛化，使得遇到未见过的状态时也能估算 Q 值。但由于近似函数（尤其是线性模型容量有限，或者使用非线性网络如 DQN 时遭遇死亡三角/Deadly Triad），它往往无法像查表法（Tabular Q-learning）那样保证完全收敛到精确的最优 $Q^*$ 值，而是收敛到一个近似解，甚至有可能发散。

### Question 13
**The Perceptron algorithm uses a linear activation function to make its final classification prediction.**
**【正确答案】 F (False)**
**【详细中文解答】**
感知机（Perceptron）算法在计算出输入与权重的线性组合（点积）后，必须经过一个**非线性**的阶跃函数（Step function，如符号函数 sign(x)），将连续的数值映射到离散的类别标签（如 +1 或 -1）上。如果是线性激活函数，感知机将无法进行硬分类。

### Question 14
**In Logistic Regression, L2 regularization helps prevent underfitting.**
**【正确答案】 F (False)**
**【详细中文解答】**
在逻辑回归以及其他机器学习模型中，L2 正则化（Ridge Regression/Weight Decay）的主要目的是限制模型参数的规模，防止模型过度拟合训练数据中的噪声，因此它是用来**防止过拟合**（Prevent Overfitting）的，而不是防止欠拟合。

### Question 15
**Batch Gradient Descent updates weights using the gradient computed over the entire training set.**
**【正确答案】 T (True)**
**【详细中文解答】**
这正是批量梯度下降（Batch Gradient Descent）的定义。在每一次迭代更新参数时，它都会遍历整个训练集来计算损失函数的总梯度，然后再迈出下降的一步。

### Question 16
**Random Forests typically have lower variance than individual decision trees trained on the same data.**
**【正确答案】 T (True)**
**【详细中文解答】**
单棵决策树（尤其是没有剪枝的深树）通常是低偏差、高方差的模型，极易过拟合。随机森林（Random Forest）通过 Bagging（Bootstrap Aggregating）技术以及随机特征选择，构建出许多差异化的决策树并将它们的预测结果取平均或多数投票，从而有效地降低了模型的整体**方差**（Variance）。

### Question 17
**The K-Nearest Neighbors (KNN) algorithm involves an explicit training phase to learn model parameters.**
**【正确答案】 F (False)**
**【详细中文解答】**
KNN 是一种典型的“懒惰学习”（Lazy Learning）或非参数方法（Non-parametric method）。它**没有**显式的训练阶段来优化或学习权重参数。所谓的“训练”仅仅是将训练数据存储在内存中，所有的计算负担（距离计算和排序）都推迟到了推理/预测阶段。

### Question 18
**The Chinese Room Argument suggests that manipulating symbols according to rules is sufficient for genuine understanding.**
**【正确答案】 F (False)**
**【详细中文解答】**
哲学家约翰·瑟尔（John Searle）提出的“中文房间”（Chinese Room）思想实验旨在反驳强人工智能（Strong AI）。该论点恰恰表明：仅仅按照预设的规则在语法层面上机械地操作符号（如计算机程序所做的那样），并**不等于**在语义层面上拥有真正的理解或意识。

### Question 19
**Reinforcement Learning from Human Feedback (RLHF) uses human preferences to fine-tune language models towards desired behaviors like helpfulness and harmlessness.**
**【正确答案】 T (True)**
**【详细中文解答】**
基于人类反馈的强化学习（RLHF）正是目前训练大型语言模型（LLMs）对齐人类价值观的核心技术。它通过收集人类对模型生成结果的偏好排序，训练一个奖励模型，进而使用强化学习算法（如 PPO）微调语言模型，使其输出更符合有用性（Helpful）和无害性（Harmless）等期望行为。

### Question 20
**Artificial General Intelligence (AGI) refers to AI systems designed for a single, specific task.**
**【正确答案】 F (False)**
**【详细中文解答】**
被设计用来执行单一特定任务的 AI 系统被称为“弱人工智能”或“狭义人工智能”（Narrow AI / Weak AI），如人脸识别系统或下棋程序。而通用人工智能（AGI / Strong AI）指的是具备与人类同等甚至超越人类的智能，能够在广泛的经济和认知任务中学习和推理的系统。

### Question 1
**In the context of search problems, what does the "state space" represent?**
a) The sequence of actions taken by the agent.
b) The set of all states reachable from the initial state.
c) The path cost from the start state to the goal state.
d) The data structure used to store nodes during search.

**【正确答案】 b**

**【详细中文解答】**
* **a) 错误**。智能体采取的动作序列被称为“路径（Path）”或“解（Solution）”，而不是状态空间。
* **b) 正确**。在搜索问题中，状态空间（State Space）定义为从初始状态出发，通过任何合法的动作序列所能到达的所有可能状态的集合。
* **c) 错误**。从起始状态到目标状态的路径成本通常用 $g(n)$ 或总代价表示。
* **d) 错误**。在搜索过程中用于存储节点的无特定数据结构通常被称为“边缘集合（Frontier）”或“已探索集合（Explored set）”。

### Question 2
**What is the primary difference between a Tree Search Algorithm (TSA) and a Graph Search Algorithm (GSA)?**
a) TSA uses a stack, while GSA uses a queue.
b) GSA keeps track of explored states to avoid redundant paths, while TSA does not.
c) TSA always finds the optimal solution, while GSA does not.
d) GSA only works for graphs, while TSA only works for trees.

**【正确答案】 b**

**【详细中文解答】**
* **a) 错误**。使用栈（DFS）还是队列（BFS）取决于具体的搜索策略，而不是树搜索与图搜索的本质区别。
* **b) 正确**。图搜索（GSA）和树搜索（TSA）的核心区别在于：图搜索会维护一个“已探索集合（Explored set / Closed list）”来记录已经访问过的状态，从而避免在有环图中重复扩展节点陷入死循环；而标准的树搜索不记录历史，可能会重复访问同一状态。
* **c) 错误**。只要条件满足（如使用一致性启发式的A*），两者都能找到最优解。
* **d) 错误**。树搜索和图搜索都可以应用于图结构的状态空间，名称的区别在于算法展开搜索树的方式。

### Question 3
**An admissible heuristic $h(n)$ used in A* search must satisfy which property, where $h^*(n)$ is the true cost to the nearest goal?**
a) $h(n) > h^*(n)$
b) $h(n) = h^*(n)$
c) $0 \le h(n) \le h^*(n)$
d) $h(n)$ must be calculated using Manhattan distance.

**【正确答案】 c**

**【详细中文解答】**
* **a) 错误**。如果启发式函数高估了实际代价，A*搜索将失去最优性保证。
* **b) 错误**。如果 $h(n)$ 始终等于完美启发式 $h^*(n)$，算法会直接找到最优解而无需额外搜索，但这在现实中极难实现，并非可采纳（admissible）的必要条件。
* **c) 正确**。可采纳的启发式（Admissible heuristic）的严格定义是它**永远不会高估**到达目标的实际代价。因此，它必须满足 $0 \le h(n) \le h^*(n)$。
* **d) 错误**。曼哈顿距离只是在特定网格问题中一种常用的可采纳启发式，并非所有问题都必须使用它。

### Question 4
**In Constraint Satisfaction Problems (CSPs), what does "arc consistency" (like in AC-3) ensure?**
a) That every variable has at least one value in its domain.
b) That for every value of a variable X, there is a compatible value for a neighboring variable Y connected by a constraint.
c) That a complete and consistent assignment exists.
d) That the constraint graph is a tree.

**【正确答案】 b**

**【详细中文解答】**
* **a) 错误**。这仅仅说明域不为空，但不涉及变量间的约束关系。
* **b) 正确**。弧一致性（Arc Consistency）针对约束图中的有向弧 $X \rightarrow Y$。它确保对于变量 $X$ 域中的**每一个**值，在相邻变量 $Y$ 的域中都至少存在**一个**值，能够满足 $X$ 和 $Y$ 之间的二元约束。
* **c) 错误**。弧一致性只能缩小搜索空间（剪枝），它本身并不能保证整个问题一定存在完整的解。
* **d) 错误**。约束图可以是任何结构（如带有环的图），不必须是树。

### Question 5
**The Minimum Remaining Values (MRV) heuristic for variable ordering in CSPs suggests choosing which variable next?**
a) The variable with the largest domain.
b) The variable involved in the most constraints.
c) The variable with the fewest legal values remaining.
d) The variable that was assigned last.

**【正确答案】 c**

**【详细中文解答】**
* **a) 错误**。选择最大域的变量通常会导致搜索树的分支过多，效率低下。
* **b) 错误**。选择参与最多约束的变量被称为“度启发式（Degree Heuristic）”，通常作为MRV的打破平局策略。
* **c) 正确**。最少剩余值（MRV）启发式（也称为“最受限变量”启发式）建议优先选择当前域中合法赋值选项**最少**的变量。这遵循“尽早失败（Fail-first）”原则，能有效修剪巨大的无解搜索分支。
* **d) 错误**。这是回溯顺序，不是变量选择启发式。

### Question 6
**A Markov Decision Process (MDP) is characterized by the Markov property, which states that:**
a) The next state's probability depends only on the current state and action, not the history.
b) All states are reachable from the start state.
c) The optimal policy is stationary.
d) The reward depends only on the current state.

**【正确答案】 a**

**【详细中文解答】**
* **a) 正确**。马尔可夫性质（Markov property）的核心是“无记忆性”。它表明，给定当前的状态和动作，未来的状态转移概率完全独立于过去的历史状态和动作序列。
* **b) 错误**。MDP并不要求所有状态都是可达的。
* **c) 错误**。虽然在无限视界MDP中存在平稳的最优策略，但这并非马尔可夫性质本身的定义。
* **d) 错误**。在一般的MDP中，奖励通常依赖于当前状态、采取的动作，甚至下一状态（即 $R(s, a, s')$），而不仅仅是当前状态。

### Question 7
**Value Iteration is an algorithm used to compute:**
a) A fixed policy $\pi(s)$.
b) The transition function $T(s, a, s')$.
c) The reward function $R(s, a, s')$.
d) The optimal state values $V^*(s)$.

**【正确答案】 d**

**【详细中文解答】**
* **a) 错误**。计算策略的是策略迭代（Policy Iteration）或在算出价值后提取策略。
* **b、c) 错误**。状态转移函数和奖励函数是MDP环境自带的已知模型参数，不需要通过算法计算。
* **d) 正确**。价值迭代（Value Iteration）通过反复应用贝尔曼最优更新规则，不断更新每个状态的价值，直至收敛，最终计算出每个状态的最优状态价值 $V^*(s)$。

### Question 8
**Q-Learning is considered an "off-policy" algorithm because:**
a) It learns the value of the optimal policy regardless of the policy being followed during exploration.
b) It requires a model of the environment.
c) It can only be used for deterministic policies.
d) It updates the policy directly without using Q-values.

**【正确答案】 a**

**【详细中文解答】**
* **a) 正确**。异策略（Off-policy）的含义是：算法用来更新/学习的目标策略（Target Policy，通常是贪心最优策略）与智能体在环境中实际收集数据时所使用的行为策略（Behavior Policy，如 $\epsilon$-greedy 探索策略）是**不同**的。Q-learning 在更新时总是使用下一状态的**最大**Q值（假定采取最优动作），而不管实际中智能体下一步真正采取了什么动作。
* **b) 错误**。Q-learning 是无模型（Model-free）算法。
* **c) 错误**。它可以处理随机环境和随机探索策略。
* **d) 错误**。Q-learning 是基于价值的（Value-based）算法，它正是通过更新Q值来间接推导策略的。

### Question 9
**In approximate Q-learning using linear function approximation, the Q-value $Q(s, a)$ is represented as:**
a) A weighted sum of features $f_i(s, a)$.
b) A table lookup.
c) A neural network output.
d) The average reward received for the pair $(s, a)$.

**【正确答案】 a**

**【详细中文解答】**
* **a) 正确**。在线性函数近似中，状态-动作对的Q值被表示为一组提取出的特征 $f_i(s, a)$ 与对应权重 $w_i$ 的线性组合（加权和），即 $Q(s, a) = w_1f_1(s,a) + w_2f_2(s,a) + ... + w_nf_n(s,a)$。
* **b) 错误**。查表法（Table lookup）是传统的表格型 Q-learning，不是函数近似。
* **c) 错误**。使用神经网络的是深度 Q 网络（DQN），这属于非线性函数近似。
* **d) 错误**。这是蒙特卡洛方法中计算回报的经验平均，不是线性近似的模型结构。

### Question 10
**Feature scaling, such as standardization, is often important for gradient descent-based algorithms because:**
a) It ensures linear separability.
b) It prevents the algorithm from converging.
c) It converts categorical features into numerical ones.
d) It helps gradient descent converge more quickly and avoids issues caused by features having vastly different ranges.

```python
import collections


def bfs_graph_search(graph, start_node, goal_node):
    # 初始化 frontier：BFS 使用队列保存“待扩展路径”。
    # 这里路径用字符串表示，所以起始路径就是 start_node，例如 "S"。
    frontier = collections.deque([start_node])

    # explored_set 记录已经扩展过的节点，防止图中有环时重复扩展。
    explored_set = set()

    # 只要队列里还有待扩展路径，就继续搜索。
    while frontier:
        # 原 BLANK 1：从队列左侧取出最早加入的路径，保证 BFS 的 FIFO 顺序。
        current_path = frontier.popleft()

        # 当前节点就是当前路径的最后一个字符。
        current_node = current_path[-1]

        # 如果当前节点已经是目标节点，直接返回整条路径。
        # BFS 第一次找到目标时，对应的就是最短步数路径。
        if current_node == goal_node:
            return current_path

        # 只有当前节点还没有被扩展过时，才继续展开它的邻居。
        if current_node not in explored_set:
            # 原 BLANK 2：把当前节点标记为已扩展。
            explored_set.add(current_node)

            # 如果当前节点在图中有邻接表，就逐个生成后继路径。
            if current_node in graph:
                for neighbor in graph[current_node]:
                    # 把邻居节点拼接到当前路径后面，形成新的候选路径。
                    new_path = current_path + neighbor

                    # 原 BLANK 3：把新路径加入队列末尾，等待之后按层扩展。
                    frontier.append(new_path)

    # 如果 frontier 被清空仍未找到目标，说明不存在可达路径。
    return None


# 示例图：key 是节点，value 是按顺序处理的邻居列表。
example_graph = {
    'S': ['A', 'B'],
    'A': ['S', 'C'],
    'B': ['G'],
    'C': ['G'],
    'G': []
}

# 设置起点和目标点。
start = 'S'
goal = 'G'

# 调用 BFS 图搜索函数，返回找到的路径字符串或 None。
```

The following Python code attempts to implement the Q-Learning algorithm for a simple 1D environment. The agent starts at state 0 and wants to reach the goal state 3. State 2 is a penalty state. Actions are 0 (move left) and 1 (move right).

There is a bug that prevents the algorithm from learning the correct Q-values. Identify the buggy line(s) of code and fix the bug in the space provided below by providing the corrected line(s) of code that should replace the buggy line(s).

```python
import numpy as np
import random
NUM_STATES = 4        # States 0, 1, 2, 3
NUM_ACTIONS = 2       # 0: Left, 1: Right
GOAL_STATE = 3
PENALTY_STATE = 2
TERMINAL_STATES = [GOAL_STATE]
LEARNING_RATE = 0.1
DISCOUNT_FACTOR = 0.9
NUM_EPISODES = 500
EPSILON = 0.1

    if state == GOAL_STATE:
        return state, 0
    if state == 0: # Start state
        next_state = PENALTY_STATE if action == 0 else 1
    elif state == 1:
        next_state = 0 if action == 0 else GOAL_STATE
    elif state == 2: # Penalty state
        next_state = 1 if action == 0 else GOAL_STATE

        max_next_q = np.max(q_table[next_state, :])
        td_target = reward + DISCOUNT_FACTOR * max_next_q
        td_error = td_target - q_table[state, action]
        q_table[state, action] = q_table[state, action] + LEARNING_RATE * td_error

```

#### 题目中文解析

这题考的是 Q-Learning 中“环境转移函数”和 Q 值更新之间的关系。Q-Learning 的更新公式本身是：

```python
td_target = reward + DISCOUNT_FACTOR * max_next_q
td_error = td_target - q_table[state, action]
q_table[state, action] = q_table[state, action] + LEARNING_RATE * td_error
```

这几行更新逻辑没有问题。真正的问题在 `get_next_state_reward` 里面：题目说明这是一个简单的一维环境，状态是 `0, 1, 2, 3`，动作 `0` 表示向左，动作 `1` 表示向右。因此正常的状态排列应理解为：

```text
0 -- 1 -- 2 -- 3
```

其中 `0` 是起点，`2` 是 penalty state，`3` 是 goal state。

所以在状态 `0` 执行动作 `0`（向左）时，智能体已经在最左边，不能跳到状态 `2`，合理结果应是留在状态 `0`。原代码却写成了 `next_state = PENALTY_STATE if action == 0 else 1`，这会让 “从 0 向左” 直接跳到 penalty state，破坏了一维环境的转移规则。

同时，在状态 `1` 执行动作 `1`（向右）时，下一步应该到状态 `2`，也就是 penalty state。原代码却写成直接到 `GOAL_STATE`，跳过了状态 `2`。这样智能体会错误地认为从 `1` 向右可以直接得到 goal reward，导致学到的 Q-values 与题目描述的环境不一致。

因此要修正的是转移函数中的两行，而不是 Q-Learning 的更新公式。

#### Buggy Lines 与修正答案

原 buggy lines：

```python
next_state = PENALTY_STATE if action == 0 else 1
next_state = 0 if action == 0 else GOAL_STATE
```

应替换为：

```python
next_state = 0 if action == 0 else 1
next_state = 0 if action == 0 else PENALTY_STATE
```

#### 修改后的完整代码（含中文注释，并标注原 BUG 位置）

```python
import numpy as np
import random


# 环境基本设置：一共有 4 个状态，编号为 0, 1, 2, 3。
NUM_STATES = 4

# 动作空间：0 表示向左移动，1 表示向右移动。
NUM_ACTIONS = 2

# 目标状态和惩罚状态。
GOAL_STATE = 3
PENALTY_STATE = 2

# 终止状态：到达目标状态后，一个 episode 结束。
TERMINAL_STATES = [GOAL_STATE]

# Q-Learning 超参数。
LEARNING_RATE = 0.1
DISCOUNT_FACTOR = 0.9
NUM_EPISODES = 500
EPSILON = 0.1

# 初始化 Q-table。
# 行表示 state，列表示 action，q_table[s, a] 表示在状态 s 执行动作 a 的价值估计。
q_table = np.zeros((NUM_STATES, NUM_ACTIONS))


def get_next_state_reward(state, action):
    """Simulates one step in the environment."""

    # 如果当前已经在 goal state，就保持在 goal，并给 0 reward。
    if state == GOAL_STATE:
        return state, 0

    # 状态 0 是最左侧起点。
    # 原 BUG 位置 1：
    # 原代码把 state 0 向左错误地转移到 PENALTY_STATE。
    # 在一维环境中，从最左侧继续向左应留在 state 0。
    if state == 0:
        next_state = 0 if action == 0 else 1

    # 状态 1 左边是 0，右边是 penalty state 2。
    # 原 BUG 位置 2：
    # 原代码把 state 1 向右错误地直接转移到 GOAL_STATE。
    # 在 0-1-2-3 的一维环境中，state 1 向右应先到 state 2。
    elif state == 1:
        next_state = 0 if action == 0 else PENALTY_STATE

    # 状态 2 是 penalty state，左边是 1，右边是 goal state 3。
    elif state == 2:
        next_state = 1 if action == 0 else GOAL_STATE

    # 防御性分支：理论上不会进入这里。
    else:
        next_state = state

    # 根据 next_state 分配即时 reward。
    # 到达 goal 得到正奖励，到达 penalty 得到负奖励，普通移动有 living cost。
    if next_state == GOAL_STATE:
        reward = 10
    elif next_state == PENALTY_STATE:
        reward = -5
    else:
        reward = -1

    return next_state, reward


print("Starting Training...")

# 多个 episode 反复训练，让 Q-table 逐步逼近真实价值。
for episode in range(NUM_EPISODES):
    # 每个 episode 都从 state 0 开始。
    state = 0
    is_done = False

    # 一个 episode 内不断选择动作、观察转移、更新 Q 值，直到进入终止状态。
    while not is_done:
        # epsilon-greedy 策略：
        # 以 EPSILON 的概率随机探索，否则选择当前 Q 值最大的动作。
        if random.uniform(0, 1) < EPSILON:
            action = random.randint(0, NUM_ACTIONS - 1)
        else:
            action = np.argmax(q_table[state, :])

        # 与环境交互一步，得到下一状态和即时奖励。
        next_state, reward = get_next_state_reward(state, action)

        # 计算下一状态下的最大 Q 值，用于构造 TD target。
        max_next_q = np.max(q_table[next_state, :])

        # Q-Learning 的 TD target 和 TD error。
        td_target = reward + DISCOUNT_FACTOR * max_next_q
        td_error = td_target - q_table[state, action]

        # 按学习率更新当前 state-action pair 的 Q 值。
        q_table[state, action] = q_table[state, action] + LEARNING_RATE * td_error

        # 状态前进到 next_state。
        state = next_state

        # 如果进入终止状态，本 episode 结束。
        if state in TERMINAL_STATES:
            is_done = True

print("Training finished.")
print("Q-Table:")
print(np.round(q_table, 2))
```
